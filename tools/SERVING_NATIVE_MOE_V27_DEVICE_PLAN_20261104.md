## Fixed coverage and limits

There are 38 ordered correctness cases: all eight ranks each run remote→live→remote at T=1; chunk/finalizer boundaries T=0,8,16,31,32,128,256,383,384,385,769,16384; one standard-norm case and one skewed-route case with a second epsilon. T=1 is covered in every rank sequence. Native route-output scratch is poisoned with NaNs before each case. Invalid/remote data must be masked before influencing outputs. T=0 compares the actual native result to the outer model's empty-result contract; stock `_forward_marlin(T=0)` is deliberately not invoked.

Actual installed standard and weight-first norm classes, their BF16 effective weights, pre-expert normalization and epsilons 1e-8/1e-5/3e-6 are used. No intermediate precision or tolerance changes are made. Nonzero references use the original official checker: whole relative L2 ≤0.015 and each row ≤5×0.015 with the original 0.1 mean-row floor. Allzero references require exact zero values. Shape, BF16 dtype, device and unchanged input bytes are checked. Each ordinary case executes stock before and after native and requires exact stock stability. A separate active rank-3/T32 stock→stock control executes before the first native forward; if this is unstable, the run reports baseline-specific failure rather than blaming native contamination.

After ordinary cases, two serial layers reuse one owner/workspace. Two additional owners share the immutable bank but have disjoint scratch/output storage. They execute on separate CUDA streams, then two explicitly captured component graphs each replay three times with changed inputs. Outputs are compared to stock after both concurrent launches; input bytes and graph output ownership are checked. This tests only the generated component graphs. It does not establish SGLang capture-pool ownership, target/draft scheduling, PDMUX, TBO, tensor/expert parallel collectives, eight-GPU correctness, allocator behavior at whole-model scale, or full prefill TTFT. Shared-owner overlap remains unsupported. The 16384-token case checks one long chunked invocation, not a whole-model prefill latency bound.

This run is **explicitly PRMT-only**. LUT zero/subnormal block-scale GPU coverage is not attempted, not silently passed or represented as an exhausted optional branch. It remains a separate qualification gap. No kernel heuristic, threshold, or unsupported-backend fallback is changed to fit the run.
