## Ownership and progress review

The route kernel uses 512 threads, matching the original `route`/gather named-barrier participants. `early_issue` is a compile-time no-op in WGS. The padded-row prefix carries across 32-job batches. CTA0 publishes job metadata and every route position, while the gather's row ranges cover activation storage without overlap; the next ordinary launch begins only after the entire routing/gather grid completes. No CPU count read or host synchronization is introduced.

Each sparse/dense CTA loads the immutable directory and follows the same grid-stride `(job, output block)` sequence in both producer warps and every consumer warp. Weight and X transfers share the original full barrier, initialized for two producer arrivals. Empty barriers require eight sparse or sixteen dense consumer-warp arrivals. The inherited weight handback occurs after all packed bytes reach registers; X handback follows WGMMA retirement, including each segment's final drain. The final CTA barrier includes all producer and consumer threads. Producer nonleader lanes return from the device helper, then join that final barrier.

Empty bins execute no matrix/TMA loop. With zero local jobs, `jrow[0]=0`, every route position is negative, gather does no work, both phases do no matrix work, and the original finalizer writes zeros without reading stale output rows. This is source reasoning and requires the targeted CPU/official tests, not an assertion of measured all-remote device behavior.

Scratch metadata occupies the beginning of the unused original fixup region after the full `ybuf`; it is overwritten each call. The original weight banks, X scratch and output lifetimes remain. Cross-kernel ordering replaces readiness atomics; no new cross-CTA spin barrier exists. The standalone launcher rejects PDL rather than silently changing its interpretation. A future decoder port must separately handle the decoder's PDL/fusion boundaries.

## Resource and cost gates

Sparse A/B require two admitted CTAs/SM at 320 threads and89,856 dynamic bytes; dense A/B require one at576 threads and231,168 bytes. Route/final each require one. Errors propagate before `ready=true`; compiler register/local allocation is measured, not assumed. This design must not silently fall back after a capacity failure.
