# V310 groups long-prompt expert routes in tiles

V310 builds on V309 and retains the six flags of the scored V204 entry. The path is eligible when sequence-parallel prefill and the Humming graph readiness probe admit grouped expert waves. In that path, each rank formerly sorted every global routing slot to construct its wave-major expert order. On an eligible rank V310 counts routes in tiles of 256 slots, scans those counts per expert, computes each wave’s expert boundaries and sorts only within each tile. The original slot position breaks ties. Each live route writes one 32-bit packed expert and slot key. The existing packer consumes this key in the same order as the parent. A 16,384-token prompt with eight routes per token produces 131,072 slots. The parent returns 1,572,864 bytes of sorted expert IDs and 64-bit slot indices. Under V309’s fused eight-wave capacity with 32 local experts, V310 allocates 590,976 bytes for packed keys, per-tile prefixes and per-wave expert counts. This saves 981,888 bytes across those arrays. The key buffer reserves space for all slots and writes only live entries. The comparison excludes the token counts, wave edges and their inputs, as well as allocator behavior and the internal workspace of the device sort. [Source and byte accounting](validation.json)

Four device kernels replace the global sort and its surrounding expert-bin construction. The token prefix and boundary search still use PyTorch. The original sorter handles small arrays, noncontiguous storage, wider expert banks and alternative integer types. The gate accepts 32 through 2,048 tiles and at most 64 local experts. The tile path introduces extra scans and indirect reads. Its net effect on elapsed serving time needs a hardware comparison. [Dispatch trace](dispatch.json)

The Triton interpreter compares the emitted wave edges and every packed key with an independent stable full sort, including rank skew, all-remote routes, terminal cuts, odd top-k and partially populated tiles. Smaller cases also run both modes of the changed production packer and compare its row map, expert keys and 13,644 activation words.
