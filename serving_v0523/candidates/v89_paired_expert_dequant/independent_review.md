# Independent V89 review

The frozen patch SHA-256 is `e20ea10ed16c9b4dec6e0d4c834ef44c086f5cbf468ee6574a5a258800da6e18`. Relative to V87, only the gate/up dequantization header changes. Its SHA-256 is `d6677fd8dafd825ae2d09ce851c3a50a412b539741e88258d90e687fcc96eb4a`. Weight preparation still maps E4M3 bytes below 8 to zero and rejects negative or NaN scales. The two packed operations reconstruct the signed FP4 operand and apply its original E4M3 group scale. The smallest nonzero final magnitude is 2⁻⁷, the largest is 2,688, and each exact product fits BF16. NVIDIA specifies subnormal support for these explicit BF16 packed multiplies. [PTX half-precision multiply](https://docs.nvidia.com/cuda/parallel-thread-execution/index.html#half-precision-floating-point-instructions-mul)

I compiled the actual shift/mask, packing and four-fragment construction on the CPU, substituting an independent BF16 instruction emulation for just the two inline PTX multiplies. All 127 × 127 combinations of admissible raw scales, all 256 signed code pairs and all four fragment positions produced **16,516,096 matching packed pairs**. The 33,032,192 scalar comparisons included **2,974,848 exact negative zeros**. The oracle independently decoded FP4 and E4M3 and required identical BF16 result bits. The CUDA graph, expert admission, accumulation order, output rounding and post-projection activation remain as reviewed in V87. [V87 review](../v87_fused_draft_head_skinny_experts/independent_review.md)

In the two real SM90 disassemblies I counted the shortest backward branch enclosing the eight HMMA sites in the sparse expert kernel. It spans `0x610–0x3040` for V87 and `0x610–0x1a70` for V89. The count fell **from 676 to 327 static instructions per K-loop body** (51.6%). Each loop retains eight HMMA and six global loads. V87 has 64 I2FP, 64 FMUL, 64 FADD and 32 F2FP. The V89 loop has 64 packed BF16 HMUL2 and no instances of those four scalar conversion/arithmetic instructions. These counts describe assembled code. Throughput and device output agreement still require an H200 execution. [Compiler log](sm90_compile.log)
