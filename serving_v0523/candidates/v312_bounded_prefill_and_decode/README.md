# V312 bounded prompt routing and decode verification

V312 combines V310’s long-prompt expert routing with V311’s decode verification attention on scored V204. The final patch is 291,856 bytes across 45 files. Applying the prompt and decode changes in either order reconstructs the same Git tree. The adjacent flags file contains the six overrides accepted for V204’s 1.5487× scored run. V312 has no private eight-H200 result or scored submission. [Official CLI export](patch.diff) · [CLI flags](flags) · [Ancestry and source verification](validation.json)

For a 16,384-token prompt, the expert workspace uses 264.11 MiB on the eligible conditional path, down from 384 MiB in V308. Replaying six route counts measured on generated single-H200 inputs retained the same number of live fused waves. With all 131,072 routes on one rank, the bound requires eight waves instead of six. The tiled router replaces the global sort and saves 981,888 bytes across the counted sort outputs and tile bookkeeping. It introduces four device kernels. The dispatch replay used the byte-identical combined sources and selected the tiled path at 7,937 slots and the original sorter at 7,936.
