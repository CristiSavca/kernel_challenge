The outer Dynamo tracer on PyTorch 2.5.1 cannot trace V123's `vars(projection)` check for instance overrides. Testing the module’s `__dict__` instead let the trace complete, but reused the clean branch after a local override appeared. V123b resolves this at the entrance to the optional fast path. Normal captured inference continues to compile the two inner convolution functions as before. The three added lines do not change the math, network payload or launch flags.
