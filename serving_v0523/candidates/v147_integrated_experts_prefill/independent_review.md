# V147 prefill and verification dispatch

The integrated target uses the FP8 cache writer only during target verification. It looks up the full or sliding-window span certificate only on ordinary EXTEND. The FP8 write in prefill still precedes attention. The merged backend passed 72 paired sliding-window wrapper runs and 63 inherited full-attention and fallback runs. The host oracle compared 57,103,104 K/V bytes and 16,128 FP32 attention output components. I also injected old full and sliding certificates into verification metadata. All 62 target layers ignored them, read the selected physical cache with the original lengths and produced zero accesses to the inaccessible raw V operand. These tests cover phase separation and the supplied tensor arguments. H200 kernel timing, final logit agreement and combined allocation peaks require a judge run.
