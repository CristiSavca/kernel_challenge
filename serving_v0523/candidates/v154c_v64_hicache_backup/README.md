# V154c measures HiCache backup coalescing on V64

This official export adds one header change to scored V64 and inherits its four launch flags. It copies contiguous runs of staged K/V pages to their host slots in one DMA per run. The model and the allocation policy retain V64’s source. The identical transport header is also available on V151 as V154. [Full control patch](patch.diff) · [Verified lineage and flags](validation.json) · [Shared implementation and tests](../v154_coalesced_hicache_backup/README.md)

The matched 16-user V64 private check delivered 17,349.9 tokens/s/GPU. The independent V68 check at the same load delivered 17,512.9. A matched H200 measurement is needed to tell how much host copy submission is exposed during serving and whether V154c improves the user frontier within the memory and TTFT limits.
