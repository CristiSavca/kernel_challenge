# V189 overlaps expert weight decoding with Hopper matrix execution

V189 changes the grouped expert down projection in V187's target verifier. The pinned Humming scheduler chooses an 8-row tile at 1–8 users, 16 rows at 16 users and 24 rows at 32 users when each request proposes eight rows and routes to eight of 256 experts. All three tile configurations use 640 threads, including 512 matrix workers, and stage BF16 inputs, packed E2M1 weights and E4M3 scales using TMA. The source keeps V187's five flags. [Exact patch and manifest](validation.json) · [Actual Humming tuning output](config.json)

The original kernel drains each pair of asynchronous output-band instructions before issuing the next pair along K. V189 groups the first two K16 slices in each K64 warp iteration, keeping their weight fragments in separate register banks. It preserves the original drain before shared-stage release, the final stage drain, the order of all FP32 accumulations and the downstream BF16 activation, scaling and normalization. At K=4,096, each CTA performs 16 K256 stages split across four K-warps. The number of waits per warpgroup falls from **64 to 48**.
