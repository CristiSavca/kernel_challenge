# V125 fused expert decode on the measured V68 parent

V125 replaces the gate/up matrix product, scaled SiLU and down matrix product with a single Hopper kernel. Eight thread blocks share one tile of up to 16 routed token rows. Each block computes all input features for its gate and up output channels, applies the original BF16 casts and scaled SiLU, and puts its activation band in shared memory. After the first cluster synchronization, each block reads all eight bands and computes a disjoint band of down-projection output channels. It writes those channels back into the original staged token rows. A second synchronization protects the next tile. Every selected expert and every feature participates. The parent applies its ordinary output scale, per-expert normalization, routing weights and slot-ordered combination. [Candidate patch](patch.diff) · [Changes from V68](delta.diff)

The comparator is V68's passing 16-user check at **17,512.9 tokens/s/GPU** and **48.0 median decode tokens/s/user**. It recorded zero short outputs and +1.7 GB/GPU peak memory over stock. V125 uses those same four flags, target attention, native-width linear draft selector, device route planner and grouped fallback. V122 has the same new expert arithmetic on the larger V117 branch, which descends from the V87 run that crashed before producing a throughput result. V125 gives the private judge a direct comparison for the expert change. [V68 official result](../../runs/04b01f958aa5487c.json) · [V87 official result](../../runs/00c134c978104d65.json)

## Work and remaining costs

For compatible dense-in-routes batches, the new operation saves two launches per eligible expert layer, up to 124 across 62 layers per target pass. At 128 and 256 verification rows of model width 4,096, the per-invocation global scratch allocation drops by 16 and 32 MiB respectively. The physical H200 must support a resident eight-block cluster for the prepared bank. The native V68 route runs on sparse batches, incompatible packing, unsupported devices and a failed optional build. The parent leaves prefill on its original path. [Adapter and preparation tests](adapter.json)

Under independent uniform top-eight routing at 128 rows, the expected cold expert bank is 849 MiB per rank per layer. The eliminated gate and activation store/read traffic is 6 MiB assuming one read per consumer. The down projection issues approximately 56 MiB of logical remote shared-memory operand reads. At 256 rows these figures are 864, 12 and 112 MiB. Cache residency, cluster scheduling, dequantization and register pressure determine the actual tradeoff. Eligibility and the full-model speedup require H200 execution. [Work model](../v122_clustered_expert_mlp/work_model.json)
