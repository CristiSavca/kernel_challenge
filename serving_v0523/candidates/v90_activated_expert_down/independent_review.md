# Independent review of V90

The frozen patch SHA-256 is `45fba4620ea380966400f7114df6070624839eff0407b2c375e92bad034f71a6`. The additional route and numerical checks passed. The H200 execution and end-to-end performance are outstanding.

The dispatch selects high routing occupancy with the required packed Humming W4A16 layouts. W13 completes on the current stream before W2 writes into the pre-existing input staging bank. The W2 output and its gate/up reader use disjoint allocations. The kernel preserves the parent gate/up scale and BF16 rounding, SiLU, the subsequent BF16 rounding, full-K FP32 accumulation, and output BF16 rounding before the existing finalizer. The pack and scale indexing match the corresponding V89 warp fragments. SM90 hardware may accumulate matrix products in a different order from the vendor kernel.

For a physical slot limit S and E local experts, at most min(S,E) experts are nonempty. With L live rows and e nonempty experts, the number of 32-row jobs is at most e + floor((L-e)/32). This is bounded by min(S,E) + floor((S-min(S,E))/32), the actual dispatch size. Every live job owns one disjoint up-to-32-row range per 512-column output band. Empty surplus jobs write nothing. Every warp makes the same dispatch decision from immutable offsets. A block-wide barrier protects shared activations between adjacent K slabs.

An independent enumeration of 66,429 expert-count vectors at the 0/1/2/31/32/33/63/64/65 boundaries checked the grid bound. Additional CPU execution of the production scan covered 24 adversarial routing plans with 3,388 live rows spread across 1–256 experts, including boundaries between 32-lane chunks. Three additional runs of the production tile with software MMA verified 224,768 BF16 outputs and preserved 11,776 poisoned inactive-prefix elements. These cases exercised adjacent 7/8/9, 15/16/17 and 31/32/33 sizes, a 65-row expert and up to three independently written column bands. [Production-code CPU harness](cpu_check.py)

At 4,096 hidden features, eight output bands repeat the gate/up reads and SiLU. At 128 or 256 live local routes with 4,096 intermediate features, the eliminated activation write plus read totals 2 or 4 MiB per sparse layer per rank. The relative cost depends on the actual expert count distribution, memory reuse, vendor tile utilization and saved launch. This estimate does not establish a throughput gain. The production SM90 compile used 96 registers per thread and no spills. [Compiler output](sm90_compile.log)
