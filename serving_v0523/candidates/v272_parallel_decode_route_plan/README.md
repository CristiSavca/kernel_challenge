# V272 overlaps two independent parts of captured expert decode

V272 is a focused comparison against V68, which passed its 16-user private check at 17,512.9 tokens/s/GPU. In V68 the main GPU stream projects the expert input while a second stream selects the experts. Both streams then join, and the main stream normalizes the rows and constructs the routing plan in sequence. V272 assigns the original planner to the routing stream and keeps the original BF16 normalization on the main stream. A single join releases the gather and both expert matrix products. Each capture allocates the four plan tensors on the consuming stream before the fork. Every replay fills them from that batch's routes. [V68 receipt](../../runs/04b01f958aa5487c.json) · [Source changes](delta.diff)

The native graph dispatch was eligible at all four tested verification widths. One independent test found that a registered, out-of-tree routing backend can write a value that normalization reads. Its native order produced 2 and an early normalization produced 1. The final patch checks the resolved router backend, module hooks, overrides and capture mode and uses V68 ordering on the custom route. The native implementation and the alternate backend both ran in the independent host fixture. [Dispatch and ordering witness](independent_capture.md)

The paired replay evaluated the frozen outer MoE dispatch, public expert entry and grouped helper on 189 rank-forwards. Across 21 eligible captures and 168 fallback cases, both versions produced identical metadata, 126,414,432 staged BF16 words and 15,803,424 final BF16 words. The fixture uses CPU Torch tensors, modeled CUDA streams and synthetic expert operations. The arithmetic kernels inside the production patch are the original V68 kernels. [Comparisons](replay.json) · [Reproducer](replay.py)

With pool, router, norm and plan durations P, R, N and Q, the two-stream segment changes from max(P,R) + N + Q to max(P+N,R+Q) assuming independent resources. The saved time depends on which stream finishes last and how much the operations compete for the GPU. The archived serving runs do not time N or Q separately. [Timing sensitivity](independent_capture.json)

The final 79,868-byte official export strictly applies and reverses against the published pin. Its launch flags match the successful V68 check.
