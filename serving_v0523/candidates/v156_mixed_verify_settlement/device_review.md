# V156 device settlement

The prepared-batch worker calls V155 once with FULL hidden capture and native physical KV ownership. It separates prompt logits from all W verification rows per tail, calls the ordinary target model sampler with the saved prompt ForwardBatch, synchronizes the prompt IDs, and runs the native DFLASH greedy chain accept and its TP synchronization. Each proposal comes from the mixed target's own input tensor. The prompt and verified tail use the ordinary draft write methods. Rejected rows are excluded by the native prefix-valid writer before it reads a slot or stores a byte. Every target input, including rejected proposals, must have a genuine pre-reserved slot. The result publishes the exact combined lengths tensor held by the next draft input. Prompt and decode results borrow slices of that tensor, and the host packs them with their own request cohorts. After sampling and acceptance, the worker clears every full-vocabulary logit view before publication and hidden materialization. The method returns None on an unsupported prepared role before invoking the target. It depends on the separate V155 target changes and V156 host result class. The scheduler must still construct physically backed mixed rows with true published prefixes and coordinate eligibility across TP ranks. This worker entry alone receives no ordinary admissions.

The pinned ModelRunner initializes its sampling observer to None, unconditionally creates its ngram manager, and reads embedding enablement from a model-config option that defaults to false. The worker refuses an installed observer or active ngram model, Mamba commit, compact draft cache, LiliCorr and Domino. It rejects grammar, non-greedy sampling, penalties, logprob/mask/hidden/expert outputs and beam effects before target execution. The guard permits TP8 and EP8, as specified by the scored serving configuration, while requiring one DP, PP, CP and DCP participant. Complete GPU admission still depends on the per-request native state and the graph planner. [Scored configuration](../../RULES.md)

It exercises eager, FULL and Breakable target bodies with emulated replay. It covers all eight possible positive commits, shuffles every physical slot, compares the complete K/V pool, tests identity of the published length tensor and verifies that logits do not survive into readback. The test also exercised 42 pre-target exclusions. Numerical fixtures use synthetic targets with BF16 taps. CPU tests emulate the TP transport, real graph replay, draft projection and the physical GPU store. H200 agreement, memory and timing remain unmeasured.
