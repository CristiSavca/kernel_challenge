# V156 settles both roles of a mixed target forward

A prepared worker call runs the V155 target once for a prompt cohort and a cohort of ongoing DFLASH requests. The prompt sampler receives its own complete vocabulary rows. Every decode chain receives all its target predictions, and the ordinary verifier chooses its committed prefix and bonus. The next scheduler iteration receives one length and bonus per live request in its original order. [Worker changes](device_delta.diff) · [Target readout](../v155_mixed_verify_graph_rows/README.md)

The draft KV writer consumes every real prompt tap and the verified prefix of each decode chain in the target’s physical slot mapping. Full vocabulary logit views are released after sampling and verification. The host retains separate request snapshots, issues both role readbacks on the same copy stream and records one completion event. It routes each role through SGLang’s existing prompt or speculative decode handler. [Worker tests](device_cpu.json) · [Host changes](host_delta.diff)

The integrated CPU worker ran 72 mixed batches across eager execution and emulated FULL and Breakable graph replay. It accepted each width from one through eight and checked every unused K and V slot. A separate test compared mixed dispatch with the two native host handlers over 192 batches and 1,152 request results, including stop tokens, output caps, retraction, chunk accounting, grammar, readback failure and request reordering. All 16 combinations of role-specific hidden and logprob copy flags retained their original side outputs. CUDA streams, device transport, and transformer weights were emulated in these tests. [Host replay](host_cpu.json) · [Worker review](device_review.md)

The official V155-based export is 147,300 bytes across 24 paths, with the same four flags as V147. Its SHA-256 is `df9d59ddc55a8b7e1bfc46a6e324cdd337d834f52fcecf19dded103bb1d10db1`. Its internal entry requires resolved inputs, real KV reservations, and agreement across TP ranks. V156 alone has no automatic admissions or H200 measurement.
