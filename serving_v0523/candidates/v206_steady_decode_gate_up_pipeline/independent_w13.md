# V206 gate/up projection review

The fused W13 path passes the shared-memory lifetime review on Humming 0.1.12. Its 640-thread CTA has one producer warpgroup and four math warpgroups. The W13 tile uses two K-warps and eight N-warps. W2 uses four K-warps and four N-warps. Each computes two native HGMMA output bands per K16, so delaying W13's stage release requires all four math warpgroups to complete their fourth K16. In all three W13 binaries the four stage-release arrivals occur after HGMMA instructions 8, 16, 24 and 32. The epilogue adds one more arrival after instruction 32. All 1,804 checked register destinations written while matrix inputs were live stayed outside those input fragments. [Disassembly checks and replay](independent_w13.json)

The stage's activation, packed FP4 weights and E4M3 scales all publish to the same transfer-completion barrier. The two 4-D maps land in its existing weight and scale regions. The shared-to-register pipeline reads the packed weight and scale, and native dequantization consumes the corresponding registers. The outstanding WGMMA instruction reads the shared activation and the prepared register operand. The fused gate/up writer reads the BF16 reduction region after all K tiles and applies its expert scale from the existing global vector. The next expert job waits for the prior epilogue, performs a fresh first-stage load and transform, and preserves the vendor's barrier epochs. The host interleaving test covered 315 schedules and 784,827 events, including back-to-back 32-stage W13 jobs and shorter tails. The final helper reproduced all three compiled device loops byte for byte and rejected all nine missing, doubled or altered includes before modifying the translation unit. [Reproducible fixture](independent_w13.py)

Actual W13 startup first tries the full-pair implementation at each supported decode width. A rejected machine image tries the earlier single-pair implementation, then the ordinary grouped Humming projection and its existing scaled SiLU. The prompt path uses its own kernel class and descriptors. The runtime fixture exercised 24 host cases, including stale weight or scale addresses, missing tuning, missing state, and launcher decline. A CUDA launch error propagates to the caller. The launcher returns a recoverable decline only before enqueueing work. The three W13 cubins retain 96 registers per thread, the same transfers, zero spills and all matrix operations. W13 saves twice as many drains per same-sized route group as the W2 change in V205. Neither the bytes nor the count of removed drains establishes the elapsed time saved. A separate single-H200 unpacking experiment measured 42.6 µs for W13 and 24.4 µs for W2. An H200 Marlin whole-expert experiment measured 130.34, 266.69, 616.16 and 791.90 µs at 8, 32, 128 and 256 input rows. Both benchmarks use a different execution path. The official V68 control measured 17,512.9 tokens/s/GPU at 16 users. V206's serving throughput and token agreement still need hardware measurement.
