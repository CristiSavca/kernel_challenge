# V289 overlaps decode routing with the pooled-input gather

V289 lets each rank assign the current tokens to its local experts as soon as the router produces their IDs. V284 waited for both the router and the pooled-input all-gather before starting that work. In V289 the planner runs on the router’s CUDA stream while the pool projection and all-gather can continue on the main stream. The existing join still precedes normalization, expert staging and both expert matrix multiplications. This applies to eligible full decode and target-verification graphs. [Production change](delta.diff) · [Full export](patch.diff)

For pool-and-gather time P, router time R and plan time Q, the segment changes from max(P,R) + Q to max(P,R+Q) with independent resources. At most the shorter of Q and the remaining pool-and-gather time can be hidden. V289 issues the same number of kernels as V284. Across 62 eligible layers, a 1.63% reduction in V64’s approximate 32-user verification period would require roughly 25 µs of exposed overlap per layer. The actual eight-H200 planner and gather times have not been measured. [Arithmetic, four loads and original timing inputs](work.json)

The four plan tensors are allocated on the main stream before the router stream forks. At the largest admitted shape the tensors occupy 24,708 bytes per rank and layer. They contain current-route metadata and remain referenced until the experts consume it. When an early plan cannot be used, the ordinary grouped path builds its own plan after the join. The earlier allocations can change peak memory in a graph pool. [Independent interleaving and allocator-order checks](independent_lifetime.md)

The production dispatch matched V284 in 34 paired host-model calls at TP4 and TP8. Fourteen used the early plan. The pairs matched 5,783,552 staged BF16 words, 4,399,104 output words and 8,592 route-map entries. These replays use CPU Torch and modeled GPU operations. A separate four- and eight-rank Gloo run exercised 204 admission decisions, including asymmetric failures. [Paired replay](replay.json) · [Capture votes](capture_gloo.json)

The 364,906-byte patch reconstructs on the official release pin. Its three-file delta preserves the Triton planner body, launch arguments and native ranked normalization source. All 720 orderings of the six launch overrides parsed. No H200 run has established throughput, token agreement, peak allocation or time to first token for V289.
