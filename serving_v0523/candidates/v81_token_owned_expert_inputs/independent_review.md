# Independent V81 review

Frozen SHA-256 `b3662cea54b86f0f4b463adcf430473184be50f82e2ff2b9467b28e717671966` matches the reviewed 154,159-byte export. The three-section delta matches the differences from V80, and every other patch section has exact parent parity. All changed Python sources compiled and the exported patch passed reverse application. It covers 28 permitted files and its longest added line is 106 bytes.

Each token owns its norm and its route stores. A prefix histogram places each local expert's rows at the same suffix offsets used by the downstream Humming kernels, counting earlier slots on duplicate routes. All ranks retain the same expert top-k, arithmetic boundaries and collective order. The global and module-specific PyTorch forward/pre-hook checks keep hook-enabled norms on their original dispatch. The effective weight includes the module's zero-centered gamma, and local output remains BF16 after FP32 accumulation and weight multiplication. The pinned PyTorch CUDA fused implementation uses the same FP32 multiplication order. The mixed-dtype implementation also widens input and multiplies the weight before returning to the input type. Reduction-order and reciprocal-square-root differences still need device measurement. [PyTorch CUDA source](https://github.com/pytorch/pytorch/blob/v2.14.1/aten/src/ATen/native/cuda/layer_norm_kernel.cu) and [mixed-dtype source](https://github.com/pytorch/pytorch/blob/v2.14.1/aten/src/ATen/native/layer_norm.cpp).

I repeated 588 production-kernel simulations and 16 guard cases, including 18,442,925 routed BF16 values. A separate randomized slot-ownership simulation covered 1,280 layouts and 352,080 slots, including 1–8 routes per token, duplicate and remote routes, and non-power-of-two local expert counts. It reproduced stable reference sorting in every case. The implementation introduces neither a host-side count read nor a new collective.

H200 throughput remains open. At low concurrency there may be too few token CTAs to fill the GPU. At larger sizes each CTA scans all route metadata for its two histograms. Saving the separate norm kernel and associated activation traffic must offset these costs. JIT, graph replay, agreement, measured peak and end-to-end throughput require official GPU checks.
