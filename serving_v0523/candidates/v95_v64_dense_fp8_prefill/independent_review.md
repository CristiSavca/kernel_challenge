# Independent review of V95

Rebuilt V95 in a private Git index at the official pinned commit `297e54fd105e974cdf401e5b4d20253a22c16f90`. Applying measured V64 plus the two-file V95 delta produced tree `985b7b1e74040fed4cd673ba89324e4dc7f35c7e`. Its complete Git diff matches the frozen 49,936-byte export byte for byte, SHA-256 `e9359287a5e70dff46449743557bf4622c121ae7adb0c36c119a1b2d7ca311e9`. The sole new module contains the exact V92 prefill packer, SHA-256 `0bcda8a24e1436dd5920b3f3acb6d859ce946337c2bd6437df7b489ed11fcc06`. All nine V64 production paths have the same contents. [Frozen delta](delta.diff)

The other changed file is the attention backend. Its constructor sets a prefill eligibility flag. The only changed forward method is `forward_extend`, which passes the packed FP8 K/V views to the existing FA3 call on eligible causal target prefill. The original request lengths, cumulative query offsets, descales and other FA3 arguments carry through. Device lengths govern the page gather. All speculative worker and acceptance code remains identical to V64. A direct evaluation of the production guard ASTs covered every combination of seven initialization conditions and twelve request conditions, 128 and 4,096 cases respectively. Both predicates selected exactly the intended conjunction. [V92 FA3 interface review](../v92_dense_fp8_prefill/independent_review.md)

This establishes an isolated V64 prefill experiment with the existing four overrides. H200 agreement, TTFT, throughput and peak memory require a private run. The per-invocation packing cap is 32 MiB. [Validation record](validation.json)
