# V281 tests sharing decoded W2 weights at one user

**Keep V278’s M8 down-projection.** Every FP4 value loaded by its 512 math lanes has one owner. An additional native Marlin W2 bank across all local experts and layers would require 17.44 GiB per GPU. Materializing just the current experts before each W2 launch adds an expected 129.20 MiB of packed-weight reads and writes per layer in the uniform routing model. None of these results justifies a new judge check. [Reproduction and receipts](check.json) · [V278](../v278_overlapped_wide_decode/README.md)

The V278 compiler input matches the previously compiled SM90a M8 W2 image. Its CTA computes 8 rows by 128 output channels at K256, with four K-worker groups. We enumerated every K16 step, warp, lane and packed-word register in the pinned Humming loaders. The 4,096 words cover 32,768 distinct FP4 values once each. An expert’s 32 channel tiles read disjoint weights, and each selected expert fits in one row tile at eight target tokens. Removing the warp-parity term as a negative control produces two owners for half the register words and omits the other half. Sharing the original decoded weights through warp shuffles can eliminate zero conversions. [Operand enumeration](check.py) · [Compiled M8 image](../v275_wide_decode_output_tiles/assembly.json)

The 2,048 unique E4M3 scale bytes in each K256 tile do have four lane uses apiece. The four lanes are already in the same warp. Electing one of the four to decode and then shuffling the answer still issues the warp’s conversion instruction and adds a shuffle. V199’s separate loader-side scale expansion for long prompts moves work between different workers. No retained M8 Humming measurement attributes a stall to scale preparation. Earlier V89 and V148 studied direct bit-level alternatives, and V69 already tested inter-CTA activation multicast. Each of the eight target tokens selects eight distinct experts from 256. The model tracks the exact occupancy distribution for 32 local experts, assuming independent choices across tokens. A second W2 bank for a single expert is 9 MiB. Even giving a batched conversion the whole 50 MiB L2, the produced bank exceeds that capacity in 77.0% of modeled passes, by 17.24 MiB on average across all passes. These are layout size and logical request calculations. Physical DRAM traffic depends on the implementation, cache policy and interleaving. A fused single-layout Marlin-compatible reader would be a separate kernel design. The retained-two-bank alternative would add 18,723,373,056 bytes before temporary workspaces against the competition’s 2 GB peak allowance above stock.
