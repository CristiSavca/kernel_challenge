# V195 combines affine full-attention reads and fused decode experts

V195 applies V192’s full-context KV reads and V191’s fused gate/up projection to the same target verification forward. On a complete 128-token tile, the metadata kernel verifies all 128 physical slot IDs. When the tile sequence covered by an attention partition is consecutive, Hopper can fetch its keys and values with tensor memory transfers. Fragmented partitions use the existing indexed path. After attention, the grouped expert W13 projection reads the existing NVFP4 banks and writes scaled SwiGLU results directly. This removes one separate activation launch per eligible layer. A missing projection variant or incompatible bank layout retains the ordinary grouped path on that rank. The official export is **185,545 bytes**, SHA-256 `dd9ebfcbf2f8b14f66e7d1ed63fafd1c4c9d441766f076ee0cbb06f835ebc0f7`. The two changes have disjoint production files. Six suites reran against the integrated source. Among them were 288 complete CPU-routed expert forwards and fallbacks, 2,125,824 independent BF16 epilogue values, native vendor cubin selection, and 720 graph metadata replays. The actual Triton kernels separately ran 30 attention calls and matched 327,680 BF16 outputs plus 819,200 FP32 partials across direct and indexed segments. Rules, sampler, verified target row count and checkpoint precision follow the frozen parents. [Integrated replay](replay.json) · [Attention interpreter](independent_attention.json)

A linked CPU test fed the first eight verification rows and 32 channels from the actual integrated attention interpreter into the sparse branch of `MuseSpark1xDecoderLayer.forward`. The ordinary and fused expert routes produced identical outputs for 40 live routed rows, using an identity post-attention boundary and modeled CPU contractions. [Retained BF16 input](independent_attention_output.json) · [Cross-phase result](linked.json)

Throughput on H200 remains unmeasured. The scored ancestor V64 achieved **1.4119×** overall, and V68’s matched 16-user check reached **17,512.9 tokens/s/GPU**. The expert path’s savings depend on live routed rows and JIT availability. The attention path’s benefit depends on how often the native allocator produces whole contiguous tiles at runtime. The combined build has not consumed a private or scored attempt.
