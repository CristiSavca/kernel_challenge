The original single-CTA planner body executed 1,608 times in a cooperative C++ warp simulator. The fixture supplies 256 simulated lanes, randomly chooses the next ready warp and shuffles lane resumption at each collective. It preserves the producer's ballots, warp-local prefix counts, atomic reservation, shared scratch, both warp fences and both CTA fences. Across 1,455 replays against previous plan contents it verified exact local-route coverage, every padded −1, per-expert original order, distinct slots, plan capacity and grid-strided consumer ownership. Empty experts, entirely remote graphs, intense skew, 31/32/33 ballot tails and 1,024 route slots were included. The measured V64 NVFP4 expert path calls the indexed Humming function below its large grouped threshold. Stock maps remote and dropped routes to −1 and leaves local IDs in the local expert range. The new adapter enters for the scored one- and four-user shapes, 64 and 256 global route slots at native width eight. At 16 and 32 users it returns to the inherited implementation. The planned W13 input row is original route slot divided by top-k, and its output is the original slot. W2 uses top-k equal to one for those input rows and writes its result back to the same slot. The existing post-expert finalizer skips remote slots, including dirty values in reused graph buffers. Both projections run on the same device stream after the planner. Their distinct output addresses make unspecified inter-expert job order harmless. There is no new cross-rank collective.

The review found an alignment issue and the final source adds the fix. A contiguous BF16 view starting at odd storage offset has an unaligned address for the W13 32-bit vector loads. The adapter now checks its address after the compile fallback. The independent PyTorch fixture ran the actual branch up to its native call or original fallback. It exercised 26 cases, including odd contiguous offsets, strided activations and IDs, non-int32 IDs, disabled specialization, compilation, empty batches, and both sides of the 256-slot boundary. The native arithmetic and wrapper compilation have separate receipts. End-to-end H200 dispatch, checkpoint rounding, timing and graph replay remain unmeasured. The 32 lanes, four `i` values and four parts cover exactly eight rows by 64 channels without overlap. The W13 and W2 producers both iterate full K in increasing increments of 16 and preserve the intermediate BF16 casts and scaling. This excludes V126’s extra partial-sum reassociation.
