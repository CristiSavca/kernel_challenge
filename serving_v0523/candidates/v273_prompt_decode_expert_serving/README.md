**Decode.** Each persistent thread block builds its expert tile offsets using one warp and one block-wide barrier. It then locates an expert with a warp vote. The released Humming schedule used three entry barriers and scanned offsets. On a recorded 256-row route distribution, one projection assigned 1,056 jobs and performed 4,976 loop-condition checks across those jobs. V273 assigns the same jobs in the same order. Each participating warp performs its own lookup. All six W13/W2 SM90a builds retained their ordered BF16 matrix instructions, 96 registers per thread and zero spills. [Compiler and scheduler checks](../v269_warp_expert_schedule/README.md)

**Prefill.** For eligible expert down-projections the wider kernel handles 256 input rows and 128 output channels per block. Two blocks share an activation transfer while computing different output channels. Its two math warp groups each process a distinct 64-channel half. The original packed weight and scale words feed the same BF16 operations and FP32 K accumulation. Before serving, the implementation queries the actual kernel's resident cluster count and prepares a narrow fallback. Humming selects the kernel using the live local row count. At TP8 with 32 local experts, a 10,240-route call keeps the narrow kernel and a 16,384-route call selects the wider one on a supported device. [Production selection and fallbacks](prompt_kernel_replay.json) · [Lane and output coordinates](../v270_wide_prompt_weight_reuse/independent_layout.json)

Under uniform top-eight routing at 16,384 rows, the wide kernel reduces modeled packed W2 requests per rank and layer from 929.8 to 716.6 MiB (22.9%). Issued tensor rows fall from 17,157 to 17,030. Full-box activation requests rise from 2,273 to 2,548 MiB. In this traffic model the extra activation bytes must reach DRAM less than 77.5% as often as the removed weight bytes for total DRAM traffic to fall. The export compiles its wide specialization with 168 registers per thread, 156,672 shared bytes and zero spills. Translating the modeled byte difference at 4.8 TB/s gives 46.6 µs per layer, or 0.43 seconds across an archived 212.78-second first wave at 32 users under the stated assumptions. This calculation does not time the new matrix schedule, dequantization, cache hits or GPU contention.
