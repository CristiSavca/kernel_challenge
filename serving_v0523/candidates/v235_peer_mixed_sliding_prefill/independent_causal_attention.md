# V235 mixed sliding attention and KV slot reuse

The frozen V235 patch (`24042d5c…`) and V233 (`3b2a0d7a…`) produced identical FP8 queries, visible K/V bytes, native cache writes, and sampled causal-attention results in six mixed graph replays and one subsequent ordinary replay. Together the paired replays compared 15,075,840 visible FP8 K/V bytes and 8,064 sampled float64 output elements. K scale was 0.75 and V scale was 1.625. [Results and source hashes](independent_causal_attention.json)

V235 selected dense varlen FA3 for a certified sliding-window layer with a 4,096- or 16,384-token prompt and two eight-token verification tails. V233 selected the paged backend in both cases. The two patches both retained the paged path for a full-attention layer, a cleared certificate, a failed cohort agreement, or a nonempty speculative mask. The test executed the native mixed-row setter, the post-agreement certificate assignment, the Muse query producer and the recorded Breakable attention callback. It supplied the cohort-agreement decision at the worker boundary. [Replay](independent_causal_attention.py)

For the next ordinary request, the test retained the first three verified slots of each tail and assigned its five rejected slots to the other request. It rebound the native page tables and write locations on the same physical KV pools and replayed the same graph with new inputs. All ten recycled SWA slots contained the new scaled FP8 K/V bytes, and both patches produced identical ordinary attention inputs and sampled outputs. Slot assignment was supplied by the fixture. The CPU replay checks the kernel launch arguments, layout and storage behavior. H200 kernel execution, GPU reduction order and serving time remain unmeasured.
