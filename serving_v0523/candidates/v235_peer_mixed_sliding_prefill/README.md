## Serving implementation

- The scheduler keeps a full prompt chunk intact. Six geometric tail capacities let the graph cover up to 256 verified rows alongside it. Native allocator availability, beam/sampling state, original slot ownership and all-rank graph admission still govern each call. The two public capacity flags are 16,640. Explicit graph lists, topology alignment and smaller memory providers govern whether additional keys can be captured. - An eligible long prompt publishes each rank's BF16 expert input shard into symmetric memory. Local experts read their required remote rows directly into their sorted W13 inputs. A full 16,384-row prompt drops the 128 MiB replicated input destination. Uniform distinct top-eight routing gives 112 → 74.13 MiB of logical incoming payload per rank per sparse layer. At the new ceiling, each rank reserves 16.25 MiB of peer storage. The CUDA allocation, peer synchronization, six extra captures and actual peak memory need measurement. Across 62 layers in a 16,384-row prompt, it removes 3.875 GiB per GPU in logical BF16 query traffic. The output of attention still has its native precision.
