# W2 width ordering and the cost of losing packed-weight locality

**V280 is archived as a negative result for promotion.** When four-way activation multicast can run only 128 CTAs against the paired kernel's 132, grouped residual widths can leave expensive tiles on the same CTA. V280 orders those tiles inside cohorts of four experts and alternates ascending and descending widths. Across the eight archived synthetic H200 route distributions this reduced critical issued tensor rows by up to 5.1% at 12,288 tokens and 11.3% at 16,384. The largest increase was 0.76% at 16,384.

A per-CTA warp initializes a shared interval table once from the actual expert offsets. Each warp then finds its expert and absolute output rows with one warp vote and shuffles. Tile enumeration preserves each contender’s packed weights, scale bytes, BF16 arithmetic, FP32 accumulation order and output placement. The occupancy query uses the actual ordered cubin after setting its dynamic shared-memory requirement. The path applies only when the quad grid is at most four CTAs smaller than the pair grid and at most one additional equal-duration work wave is possible for the current row count. Wider gaps and longer input ranges keep V274's paired schedule. The ordinary V274 quad path remains available at equal grid sizes. The mixed-cache model estimates that the reordered experts lose more weight locality than the operation-count comparison reveals. It replays actual overlapping activation-source intervals, packed weight/scale tiles and optional output write allocation through a cold, fully associative cache. The ranges cover eight ranks, three intra-wave arrival orders and both output allocation policies. All numbers below are additional A+B read misses relative to the 132-CTA pair.

| Shared A/B/output cache capacity | 12,288 tokens | 16,384 tokens |
|---|---:|---:|
| 18 MiB | +217.9 to +321.1 MiB | +34.5 to +213.0 MiB |
| 36 MiB | +222.7 to +321.1 MiB | +86.1 to +249.0 MiB |
| 50 MiB | +0.8 to +204.6 MiB | +18.5 to +122.4 MiB |

At 12,288 tokens, rank 3 with a 50 MiB cache, lockstep K access and allocating output stores moved from 94.1 MiB of activation reads and 288 MiB of packed weights to 114.2 MiB and 432 MiB. A weights-only cache at 36 MiB predicted zero excess reads for this rank and load. Full-box activation requests still halve, but the modeled L2 misses and their sensitivity to other clients make V280 a poor promotion choice. No official check or H200 run was launched. The CUDA 12.9.86 build produced native SM90a using 168 registers per thread, 156,672 bytes of dynamic shared memory and no spills. The 512-byte interval table requires a 1,024-byte-aligned dynamic allocation for the original shared-memory swizzle. The repaired image’s ELF shared section is 2,048 bytes with alignment 1,024, and its SASS constructs dynamic base 0x800. The native quad image starts at 0x400. Both start in swizzle phase zero. The final CUDA function’s real residency still requires hardware. Independent host execution of the production header covered 1,937 layouts, 311,232 returned lane values and 1,497 backwards transitions in native tile indices. Removing the ascending-cohort tail placement failed its negative control. [Disassembly](sm90a.json) · [ELF and address proof](alignment.json) · [Live public-contract replay](validation.json)

A host-only follow-up assigned each resident wave’s longest tile to its least-loaded eligible slot while preserving the exact set of experts and weights active in that wave. The critical tensor-row proxy changed by −6.0% to −1.8% at 12,288 tokens and −10.7% to +0.76% at 16,384. The 50 MiB cache model added 0–3.9 MiB at 12,288 and 0–36 MiB at 16,384. This alternative would need cumulative load decisions on the GPU and hardware timing. [Within-wave analysis](within_wave.json) · [Cache replay](shared_cache.json)

The full 401,000-byte candidate uses V248 plus the V270 and V274 W2 deltas, with a 7,993-byte V280 increment. Its ordinary one-line context export passes strict forward and reverse application. The native baseline and ordered candidate are research artifacts. The corrected V274 W2 remains the promotion choice.
