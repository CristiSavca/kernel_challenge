# V115 device-controlled expert waves

V115 changes large-prompt MoE execution on V102. The two grouped Humming GEMMs, activation, packing and expert finalizer now share one CUDA graph loop body per layer. A GPU predicate replays that body until every input token on the rank has a local output. V102 records the body nine times for a 16,384-token chunk to accommodate the most skewed legal assignment. V115 records it once and can still execute all nine waves. Decode and target verification use V64's existing paths. [Export](patch.diff) · [Delta from V102](delta.diff) · [V102](../v102_v64_graph_grouped_prefill/README.md)

The loop reads the first and final token of each wave and copies the actual expert offsets into parent-owned buffers. A wave containing only remote experts can still own token rows. Using token bounds as the stop condition allows the finalizer to write their zero local contributions. Every rank exits independently before it reaches the parent graph's next collective. The ordinary eager path uses the same metadata kernel for warmup. A startup probe checks both a two-iteration and a zero-iteration replay. Older runtimes, incompatible allocators and short schedules use V102's fixed loop. The graph registry keeps separate executables for captures that own distinct CUDA conditional handles. Each row uses 512 synthetic rank samples. Each token picks eight distinct experts uniformly from 256, of which 32 are local. The count includes the packer, two GEMMs, activation and finalizer. The new metadata and graph-condition updates have their own cost. Learned routing, NCCL waits, graph allocation and H200 timing determine the actual serving effect. The CPU graph executor compared 55,296 BF16 outputs in 192 cases, including arbitrary skew, all-remote tokens, duplicate assignments, exact-capacity tails, capture and eager fallback. A separate run in the Triton interpreter covered 172,487 tokens and 258,655 live routes across 28 layouts, including the full-size geometry. The eight new Hopper specializations assembled with zero spills. The V102 dispatch suite also passed its 11 cases and six two-rank readiness votes. Physical CUDA replay, TTFT, memory and throughput still need an H200 check. The real-device replay fixture can check six changing histograms on one captured metadata loop when a compatible GPU is available.
