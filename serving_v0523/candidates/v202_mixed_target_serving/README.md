# V202 shares one target forward between prompt and verification requests

**Scheduler correction, November 19.** On the production mixed-batch entry, V202–V206 run the target outside the owner-projection context. V203–V206 also leave the sharded verification-head flag at its default. The earlier component tests enabled those features through a separate helper. Queued V204/16 measures mixed batching and expert changes with the full vocabulary gather and raw context features. V209 connects both optimizations to the production scheduler. [Scheduler replay and source](../v209_mixed_prompt_context_entry/README.md)

V202 brings V194's mixed scheduler into V198's sequence-parallel model. An eligible prompt and the entire running verification cohort share a target-model pass. Each token owner computes the draft model's original full-width feature projection and RMSNorm. The ranks gather those normalized features once, and the ordinary prompt writer and prefix-valid verification writer consume them. The LM head uses one row per prompt plus every verification position. The normal full-gather path handles larger selections. This design also keeps captured-body padding out of the true request row layout. [Official export](patch.diff) · [Changed source](delta.diff)

Two 8-token verify chains plus a prompt with 12 token rows, for example, require 17 vocabulary-head rows and 28 target-feature rows. Both chains are evaluated in full. If they commit two and seven tokens, only those two and seven verification rows enter their draft caches. The target accepts real draft tokens with its native greedy rule. Per-request state, positions and KV locations follow the original slot assignments. For a standalone prompt the optional paired-KV endpoint remains available. [Model and cache checks](independent_review.md)

The independent CPU run tested 45 mixed targets and 23,670 rows with normalized and raw features, selected and dense head gathers, and both graph backends. It checked 295,668 logits and preserved 2,985 rejected cache slots. Another 96 scheduler rounds emitted 1,008 accepted tail tokens and carried the correct bonus and lengths into the next filtered step. The fixed-capacity continuation replay covered 14,000 complete prompts. The graph and model bodies are represented by CPU fixtures.
