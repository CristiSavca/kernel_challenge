# V246 writes new mixed-batch FP8 rows into the dense prompt buffer

On a single-prompt mixed call, V246 allocates two contiguous FP8 banks and writes the prompt and running requests directly after the visible prefix. The ordinary KV writer publishes every row into the model's physical cache. The running requests attend to that cache. Once the writer and verifier have used their inputs, a Triton kernel gathers the prompt prefix and zeroes the 256 padding rows around the dense FA3 call. The kernel skips the entire interval that already holds the newly converted prompt. Multi-prompt batches and unsupported layouts take their previous paths. For each eligible 16,384-token chunk, one eliminated FP8 read and write per prompt row removes 8 MiB of logical copying per full-attention layer per GPU. The archived eight-H200 V41 cold wave had 21, 58 and 115 qualifying single-prompt joins at 4, 16 and 32 users under the V241 admission replay. Across 16 full layers this corresponds to 2.625, 7.25 and 14.375 GiB per GPU over those waves. The 4-user figure sums two repetitions. The one-user wave had zero mixed joins. The trace records a different serving binary and supplies no elapsed-time gain for V246. [Replay script](work.py) · [Trace hashes and bounds](work.json)

The allocation guard accounts for the entire backing storage and the concurrent split-verification workspace. All 21 near-limit fixtures passed. Some shapes now hold a larger FP8 allocation while the tail is running. The retained parent guard still limits admission, and the 32 MiB local cap covers only named temporaries. GPU allocator reservation, FA3 internals and whole-server peak still need a physical measurement. [Thresholds and stream ordering](independent_lifetime.md)

All 28 SM90 specializations assembled. The 26 builds for other configurations, including the serving shape of 128 features per row, used zero spill bytes. The two widest inline configurations at 1,024 features per row used 36-byte spill loads and stores. The production Triton interpreter matched both implementations and an independent oracle across 20 cases, comparing 92,608,512 packed bytes and checking 61,161,600 bytes of physical-write input. The normal Muse/graph host replay exercised 20 paired paths. Independent delayed-store tests also demonstrated the expected corruption when the required stream wait was intentionally removed.
