The original owner of a sequence shard normalizes each expert input before transport. V163 gathers the actual scores and IDs, obtains an ownership bitmap from every participating rank and uses score-slot order throughout the native grouped path. Negative slots, repeated experts, remapped banks and multiple local experts belonging to one token are accounted for independently. The compact row index maps each live original token row to one received BF16 row. With hidden width at most intermediate width and the count of local slots bounded by all slots, the existing grouped arena check cannot switch to the indexed kernel on compact data.

The independent test ran the candidate exchange with real Gloo split collectives. It compared 379,008 BF16 output elements across 672 rank cases at TP2, TP4 and TP8. Asymmetric forward hooks, pre-hooks, a compiled call, instance overrides and an unsupported foreign rank triggered dense mode coherently. A separate synthetic expert function checked the sparse rows, stable map and route-weighted outputs against the same function on a dense gather. Inactive receiver ranks entered every required group, including empty sends and receives. TP8 exercised pass widths 1, 2, 4 and 8. The backing pointer and allocation size checks held for all sparse destination groups. [Test driver](independent_transport.py) · [Results](independent_transport.json)

The dynamic transport belongs inside the existing eager break. The CUDA graph surrounding it can preserve stable input and preallocated output addresses while a replay recomputes different routes and split sizes. Variable split arrays use the TP device process group. The pinned PyNccl equal-split helper cannot express that protocol. The synchronous distributed call must publish its work dependency on the caller's stream before another destination group overwrites the send buffer. The same producer/consumer ordering is needed before the original finalizer and output reduction. Gloo does not test NCCL stream behavior or BCG allocator peaks.

If eight different experts are selected uniformly from 256, a token has an expected 5.295 owning ranks at EP8. For a 16,384-row BF16 input of width 4,096 this reduces average logical remote payload per rank from 112 MiB to 74.13 MiB. The 37.87 MiB difference corresponds to 88–265 microseconds at an *assumed* 450–150 GB/s. Repeated variable collectives, mask exchange, the host read, search, packing, GPU stream handoffs and rank skew compete with that budget. Sending every token to all eight owners saves no bytes.
