# V308 runs compact prompt waves on the V204 serving path

V204 passed its official 16-user private check at 18,338.6 tokens/s/GPU, 1.489× at the stock comparison point. V308 keeps that build’s six flags and mixed-batch handling. For an eligible large prompt, it removes the route-count read that synchronizes GPU and host in each expert layer. The first fused gate/up wave executes in the parent graph and the GPU processes any overflow. Every active route still runs both projections. Ordinary decode keeps V204’s path. [V204 private result](../../runs/7fcdf9abf39b486a.json) · [Full export](patch.diff) · [Delta from V204](delta.diff) · [Flags](flags.json)

V204’s original prompt routine selects a down-projection kernel that unpacks weight scales on the loader warps. Direct application of V306’s delta would bypass that kernel during wave execution. V308 shares the W2 dispatch between ordinary prompts and waves. A current weight and tuner binding selects V204’s W2 kernel. Other bindings take the vendor grouped kernel. Either W2 selection also supports a declined fused gate/up binding. [Source changes](delta.diff) · [Joined dispatch and numerical replay](joined_replay.json)

The ordinary TP8 EXTEND path with layernorm sequence parallelism gathers all expert inputs, scores and IDs before calling the expert module. The graph path starts at 8,192 rows for top-eight routing over 256 experts when device and capacity checks pass. At 16,384 rows V306's compact layout fits 24,576 local routes in the 384 MiB BF16 arena used by the original wave layout. Its row-key array grows by 32 KiB. V204's eager scratch is data-dependent. GPU peak memory, overlap with mixed-batch state, time to first token and per-load throughput must be measured on the integrated build. ## Verification

- All 180 joined CPU replay cases matched 53,280 BF16 output words with 19,908 live routes. The actual W2 binding and launch adapter passed the offset vector through to the modeled device operation. Its custom and vendor paths executed 200 and 400 waves with nonempty, right-aligned suffixes, plus 281 and 562 empty waves. Tests exercised 45 conditional runs with up to 12 overflow iterations. [Numerical replay](joined_replay.json)
- C++ host execution of the published Humming 0.1.12 persistent expert scheduler matched all 160,624 checked tile addresses, including repeated M tiles, skipped tiles, empty experts and nonzero first offsets. [Native address test](native_scheduler.json)
- The wave metadata and packing kernels, seven native launcher registrations and V204’s W2 source match their compiled donors. The integrated mixed-batch replay checked 96 scheduler rounds, 1,008 committed tokens, six local-head cases and 42 full-head cases. [Source and compiler provenance](inherited_kernels.json) · [Existing native bindings](native_bindings.json) · [Mixed scheduler and target regression](mixed_regression.json)
- The 283,876-byte export changes 44 allowed files. Strict forward and reverse application recovered the exact published base and V204, and the six flag overrides agree with the passing run. The tests above did not execute V308 on an H200. [Public contract and reconstruction](validation.json)
