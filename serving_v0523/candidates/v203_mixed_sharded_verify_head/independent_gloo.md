# Distributed mixed-head settlement

A real Gloo process group at tensor-parallel sizes four and eight ran the native mixed/full LM-head producer, the pinned `finish_deferred_gather`, `deferred_argmax(first_nan=True)`, mixed settlement, native prompt sampler, greedy acceptance, result packing, and the fixture's CPU cache writer. Each topology ran eight paired cases. Every rank ran both full and sharded settlements (192 native prompt sampling and acceptance calls across all ranks). The native gather and argmax Triton wrapper and kernel bodies were evaluated with checked CPU pointer operations, a pairwise leftmost reduction and NumPy FP32 tanh. CUDA graph capture, libdevice accuracy at all inputs, NCCL and H200 timing require separate evidence. [Source-bound results](independent_gloo.json) · [Fixture](independent_gloo.py)

For the two world sizes, 622,202 and 1,245,298 vocabulary values respectively matched full, capped, global-order logits. The worker issued one full-vocabulary collective for prompt rows and a separate two-FP32-values-per-tail-row collective. All prompt IDs, committed tail outputs, accepted lengths, bonus tokens and published sequence lengths matched the full-gather route. The test includes 4,111-column local shards crossing the 4,096-wide reduction tile, one entirely padding-filled rank, cross-rank ties, saturated logits, positive/negative infinity, signed zero and 66 live tail rows with valid NaNs across the two topologies. Every invalid vocabulary column was poisoned even in the finite controls. Saturated ties and NaNs used the lowest valid global vocabulary ID.

Before each paired settlement the actual producer also took both branches with the same logits: the full route gathered every row, and a selected mixed output returned its rank-local tensor with no collective. Eight adverse admissions per case placed bias, linear, additive or scaling penalties alternately on a prompt or a decode request. All 768 rank-level adverse admissions declined before the target. The normal prompt fallback then applied real additive penalties and logit bias in its native sampling routine (192 individual rank calls) and selected the changed token in every case.

The target's ordinary dense Muse LM head supplies equal-width, contiguous FP32 shards on the native TP configuration. Producer and consumer communicate with the same TP coordinator. Runtime support still assumes consistent collective participation across ranks. The independent test uses identical standard head layouts and the same accepted sampling mode on each rank. It does not establish a fallback for rank-local modifications that change collective selection.

Reproduce with `python independent_gloo.py /path/to/integrated/sglang nan` using a CPU PyTorch build with Gloo and NumPy. The recorded CPU run used PyTorch 2.5.1.
