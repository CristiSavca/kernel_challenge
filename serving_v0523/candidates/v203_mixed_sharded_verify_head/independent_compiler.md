# Mixed greedy head compilation

The H200-targeted compiler produced 12 cubins with Triton 3.8 and NVIDIA ptxas. The row kernel uses 64 registers with zero spills in both modes at each tested pointer alignment and stride type. Its native default emitted exactly the same executable PTX as the pinned parent. The dense softcap materializer uses 44 registers. Every build has the same FP32 divide, CUDA libdevice tanh and final multiply sequence; the generated special-function path uses the same exponent and reciprocal instructions. The mixed variant emits unordered FP32 predicates and maps live NaNs to positive infinity after the softcap. Valid finite caps bound numeric results, preserving the native dense argmax’s first NaN. Equal numeric values, either sign of zero and saturated ties keep the lowest token ID in a rank and then across equally wide ordered shards. Empty shards publish negative infinity. A Triton CPU interpreter run compared 252 final global winners with the dense materializer on contiguous, uneven and fully padded shards, 4,096-column boundaries, 84 rows with live NaNs, 56 signed-zero rows, and 131 rows with tied numeric maxima. All 1,248 guard words survived. The CPU interpreter has no CUDA implementation of libdevice tanh. The fixture supplied the same NumPy FP32 tanh to each native kernel while leaving every load, mask, index, reduction and store in Triton. The pinned default’s all-NaN tile raises in the interpreter’s NumPy reduction, so executable PTX equality covers that particular legacy edge. Native H200 numerical execution and latency remain unmeasured. [Interpreter result](independent_interpreter.json)

The mixed output's local vocabulary shard reaches the dedicated verifier only after eligibility excludes beam/logprob and sampling overrides. Each prompt receives the ordinary fully materialized logits and sampler. Only target predictions reach the mixed tail acceptor, which clears its logit views before the result leaves the forward stream. The request’s mixed row selection and shard flag are propagated to the static body-replay view. The real logit producer passed 64 valid local-shard returns and 1,872 full-vocabulary fallbacks with TP2/3/4/8, including tiny vocabularies, padding exactly equal to vocabulary size, undercoverage, nonnormal caps and the FP32 exact-ID limit.
