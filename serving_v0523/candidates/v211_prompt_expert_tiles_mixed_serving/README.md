## Changes on the serving path

- On a long prompt, the grouped gate/up and down-projections choose the tensor-core row width at the last tile of each expert. They use 32, 96 or 176 rows with the original physical pitch, weight blocks and full reduction over the input channels. Both kernels compiled for SM90a. The new branches have zero local loads and stores in the steady K loop. The original 176-row loop keeps its instruction count. Under independent uniform routing the expected padding reduction is 19.39% at 8,192 rows and 5.64% at 16,384. This measures tensor-core row work. [Generated machine code](../v208_residual_prompt_expert_tiles/sm90a.json) · [Operand replay](../v208_residual_prompt_expert_tiles/operands.json) · [Independent register and expert-boundary checks](../v208_residual_prompt_expert_tiles/independent_layout.md)
- The expert finalizer applies each expert's native BF16 down-projection scale while reading that expert's output for normalization. At 16,384 live local routes of width 4,096, it removes 256 MiB of logical reads and writes per rank and eligible layer. Both signs, rounding, remote routes and indexed fallback were checked. The compact long-prompt path requires at least 65,536 routing slots and an eager or breakable expert callback. Ordinary full graph capture and compiled routing use their existing indexed path. [Callback A/B](../v207_prompt_down_scale_finalization/callback.json) · [Triton arithmetic](../v207_prompt_down_scale_finalization/finalizer.json) · [Independent production dispatch](../v209_mixed_prompt_context_entry/independent_production_review.json)
- During a mixed target pass, every GPU scores its vocabulary shard. The ordinary prompt sampler receives the full scores. Eligible greedy verification gathers each rank's winning score and token ID for each tail row. Sequence owners compute the original projection and normalization before gathering draft context. The scheduler coordinates head eligibility before launching the target. The cache writer commits the accepted prefix of each tail. ## Integrated check and open hardware measurements

The integrated test compared 1,048,576 finalized BF16 words between V206 and V211 and used a 640-word slice as the synthetic target's token-dependent hidden states and taps. It executed 168 complete scheduler rounds in 84 paired comparisons over four- and eight-rank Gloo groups. It also exercised eight rank-disagreement fallbacks. The assertions cover prompt and bonus token IDs, acceptance lengths, next-round state, physical cache addresses, rejected positions, full-width observer hooks, and the collective payload shapes. The grouped host callback and scheduler run from candidate source. CPU operations model GPU expert GEMMs and the captured transformer body. On an archived latency replay, even instantaneous generation after the first token with cold latency held fixed produced scores of only 2.37–2.48× across low-load repetitions.
