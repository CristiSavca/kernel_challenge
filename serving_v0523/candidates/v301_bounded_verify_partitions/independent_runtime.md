# Public attention dispatch and mixed-tail limits

The public V301 function preserves V297's split order over 3,000 modeled layouts, including all supported maximum query lengths from 2 through 16 and 8,880 empty query requests. All 68,955 nonempty request/partition intersections retained their original partial slot and tile bounds. The test exercised all six fixed certificate widths and the dynamic path. Removing the mid-tile allowance underestimated live SWA tiles in 536 layouts. The replay executed the native scalar tile geometry, both actual backend call expressions, the public launch wrapper, allocation decisions and descriptor checks. Kernel arithmetic was outside its scope. [Source](independent_runtime.py) · [Results](independent_runtime.json)

At the released H200 geometry a single long-context sliding layer launches 68 partition CTAs instead of 132 and reserves 1,131,520 instead of 2,196,480 bytes of partial workspace. Larger batches retain 132 partition CTAs. The single-request sliding case reads one certificate directly. Sliding batches 2, 4, 16 and 32 retain V297’s 32-lane certificate scan. One long full-attention request retains all 264 CTAs and can inspect eight certificate lanes for its bounded segment. Earlier V248 shared multi-request partition metadata across layers and retained the one-request scalar path. V301 changes per-kernel scheduling on a single request and narrows eligible full-attention certificate scans. Elapsed time for this work on the serving model remains unmeasured. [Geometry](independent_runtime.json) · [V248 design](../v248_shared_verify_raster/README.md)

A changed workspace cutoff can admit a custom mixed-tail kernel where V297 declined. A long-history single-request SWA tail changes paths at a caller-supplied budget between 1,131,520 and 2,196,479 bytes inclusive. The two implementations also separate with short full tables. At the public maximum of 16,640 total rows, FP8 write operands use at most 4,259,840 bytes for two K/V heads of width 64. The mixed caller therefore retains at least 29,294,592 bytes from its 32 MiB allowance, comfortably above V297's maximum public full-tail scratch of 5,424,640 bytes. The ordinary verify caller has no such budget. Numerical equivalence to the fallback in other configurations is a separate question from identical partitioning.
