# V120b enables sequence-parallel draft-context projection on Muse prompts

The served model constructs `MuseSpark1xLogitsProcessor`. V108, V111 and V120 accepted only the exact base `LogitsProcessor`, which disabled their prompt projection on Muse. V120b also accepts the native Muse processor. Muse changes the LM-head multiply and inherits the base pruning and auxiliary-state capture. V120b retains the original projection for unknown processors, custom capture methods, module hooks and incompatible ranks. V120's independent output-channel split on verified decode rows remains in the parent patch. [Two-function correction](delta.diff) · [Full submission](patch.diff) · [Parent implementation](../v120_phase_parallel_draft_context/README.md)

At TP8, a full 16,320-token prompt chunk with five 8,192-wide BF16 taps would materialize a 1,275 MiB all-gather result in the ordinary path. The new path applies the complete 40,960-wide dot product on each rank's own rows before the gather. It gathers a 255 MiB result instead. The corresponding peer bytes received per rank fall from 1,115.625 to 223.125 MiB and the projection falls from 10.952 to 1.369 TFLOP per rank. Every token is still projected. The gather size includes the local rank's rows. These are logical tensor sizes and operation counts for a full eligible chunk. [Projection and traffic model](../v120_phase_parallel_draft_context/flags_traffic.json)

A distributed CPU regression reproduced the old rejection on every rank and exercised Muse's own logits forward, hidden-state pruning and native draft projection. It compared 144 calls across TP2, TP4 and TP8 covering short, boundary and padded prompts, token and embedding inputs, a custom subclass and per-rank overrides. All BF16 normalized draft features and sampled FP32 logits matched. The harness implements the CUDA-only FP32-output head matmul with CPU FP32 operands for its dyadic inputs and omits the vocabulary-shard exchange. An independent replay traced the registered model's constructor and the real DFLASH worker discovery. [Prompt fixture](muse_prompt.py) · [Results](muse_prompt.json) · [Independent constructor trace](independent_processor_dispatch.json)

The inherited suites passed 69 distributed prompt cases, 24 verify cases, 48 prompt appends and six empty worker calls. Exporting with the official CLI produced 97,151 bytes across 20 permitted Python files. Applying the parent and delta reproduces the frozen submission, and the patch reverses cleanly on the pinned release. The export retains the parent's 11 launch flags. The November 19 private runner selects V120b at 32 users after the confirmed V87 crash and V64 pass. V64 scored 1.4119× across all four loads and recorded 20,547.4 tokens/s/GPU at 32 users. V120b still requires H200 verification of model agreement, lengths, peak memory, time to first token and throughput.
