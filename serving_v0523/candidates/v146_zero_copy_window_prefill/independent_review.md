# V146 sliding-window prefill review

For each request, omitting `max(0, K−Q−left)` cached tokens shifts its logical query and key positions by the same amount. FA3's lower-right mask therefore sees the same physical key at each valid position. I compiled the pinned native `BlockMN` implementation and compared its tile bounds and physical offsets before and after cropping. All 460,800 comparisons agreed, including GQA packing, up to four KV splits, odd query lengths and 74,160-token prefixes. On SM90 the dense specialization uses TMA for K and V and applies the local tile offset to both descriptors. The existing page-one paged local path already skips old keys at the query-block level. V146 changes the load mechanism. The real V143 and V146 backend methods passed 72 paired runs on host FP8 storage. Twelve reached the new dense path. Across them, 57,103,104 selected K/V bytes and 16,128 FP32 reference output components matched, including logit softcap and per-head descales. Sixty fallback calls retained the parent buffers, table and lengths. Cases included distinct global and SWA layouts, unequal original K lengths, mixed Q with equal visible lengths, stale or changed table/length/query buffers, layer-specific windows, poisoned retired logical slots, ready/pending events, graph padding, current capture, special options and out-of-bounds backing. Three simulated consumer streams received allocation registrations for the cropped length vector. The inherited full-attention suite also passed on the final sources, including successful dense and coalesced full-page routes. The tested call preserves the query offsets, scale, softcap, window, split setting, output destination and the original cumulative new-key argument. The dense cache length supplied to FA3 is the live cropped extent. With no appended keys, the pinned native forward leaves its appended-key pointer unset, including when the Python wrapper passes the original cumulative new-key vector. The normal FA3 prefill graph refreshes this batch's metadata before each eager attention break. A different layer window or stale metadata falls back. Exact GPU floating-point agreement, elapsed time, and the percentage of real requests with a contiguous translated SWA suffix still require an H200 run.
