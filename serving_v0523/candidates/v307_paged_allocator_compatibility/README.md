# V307 repairs the 160-token page allocator on V120b

The V120b judge job at 32 users stopped during allocation for the first request and returned no throughput. The captured error names an unsupported `next_power_of_2` function. The submitted Triton kernel called that Python helper from inside `tl.arange`. V307 calculates the power-of-two vector width in the two existing host callers. The allocator still uses the actual page size for page counts, division, slot addressing and tail masks. This retains 160-token pages while using a 256-lane vector for the two partial-page stores. The original seven-argument kernel entry remains usable for native power-of-two pages. [Official crash and traceback](../../runs/a73535cda6bf4cac.json) · [Three-file change](delta.diff)

The CPU-only compiler VM runs Triton 3.8.0, which exposes the helper as a decorated constexpr function. The original parent compiled in that configuration. Passing the corresponding undecorated Python function into the same compiler reproduced the judge's diagnostic at 160 tokens. The repaired kernel compiled in both configurations and emitted byte-identical sm90a machine code for 32 requests with 64-bit lengths. All 33 candidate specializations assembled without register spills. The judge image's exact Triton version remains unverified. [Compiler control and builds](sm90.json)

The CPU interpreter executed the real parallel allocator stores and compared them with a sequential page-by-page allocation. It checked 261,322 slots over 1,520 requests. Cases covered page sizes 1, 3, 64, 160 and 256, nonconsecutive free pages, zero extension, previously filled pages, crossed page boundaries and extensions longer than 4,096 slots. Guard words remained intact. Both the paged allocator and the multi-ended allocator provided the tested launch geometry. An additional 72 cases covered the original call signature for power-of-two pages. [Interpreter results](interpreter.json) · [Reproduction](kernel_check.py)

The full 98,536-byte patch exports 22 permitted Python sources. The 2,088-byte delta changes three files from the exact V120b tree. Both patches apply and reverse cleanly, preserve existing file modes, and retain all 11 flags from the failed job. Nine earlier exports include the incompatible JIT call. The V132 check already requires V120b to pass at 32 users. V307 has no full-model correctness, GPU memory, time-to-first-token or throughput result. It has no judge reservation.
