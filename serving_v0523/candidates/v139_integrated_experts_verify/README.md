Its serving speed, correctness, TTFT, interactivity and GPU memory await a physical H200 run. The only overlapping files among these three changes were the expert adapter and environment defaults. Each expert JIT retains its own switch and failure handling. The layer still constructs a single pair of packed expert banks. Integrated preparation calls the compact activation compiler before releasing checkpoint tensor attributes and evaluates the native projection dispatch using the verified prepared-bank layout. All four V136 files are byte-identical to the corrected standalone release, as are both expert CUDA headers, the weighted finalizer and the layer-level grouped frontend. The unchanged flags are `--enable-layernorm-sp`, `--moe-runner-backend humming`, `--speculative-moe-runner-backend marlin` and `--swa-full-tokens-ratio 0.25`. The local official export applied and reversed against the pinned base and V64. [Manifest with four source hashes and per-file provenance](validation.json)
