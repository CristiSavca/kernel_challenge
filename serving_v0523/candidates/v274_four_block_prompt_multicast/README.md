# Four-block activation multicast for long-prompt W2

V274 builds on V270’s 256-row, 128-output-channel down projection for grouped BF16 activations and packed FP4 expert weights on Hopper. Each four-block cluster reads one shared 256-row activation tile for four adjacent output-channel tiles. Each CTA retains its own packed weights, scales, K reduction order, BF16 output epilogue and 32/128/224/256-row residual dispatch.

The constructor admits four-way multicast when the actual cubin’s driver residency can sustain the same CTA count as the two-way launch, and the original CTA grid and output-channel geometry divide evenly into groups of four. The paired and native narrow paths remain available when preparation or occupancy checks fail. Production decisions use public geometry, tensor bindings and CUDA occupancy. Four-way multicast also revealed a shared-memory lifetime hazard inherited from two-way multicast. A fast leader could begin the next persistent job’s activation transfer while a follower still read its prior output from the same region of shared memory. In both shipped multi-CTA variants, each follower’s producer signals rank zero after its math threads finish and it executes the existing generic-to-async proxy fence. Rank zero’s epilogue barrier waits for these signals before the next broadcast. The last-job cluster exit barrier keeps every CTA’s shared memory alive. An independent event-order replay covered initialization, repeated parity and exit, with negative controls for a local-only or math-only acknowledgment. V270 and the initial V273 W2 image predate this fix. [Independent source-bound epilogue checks](../v277_multicast_prompt_gate_up/independent_fence.md)

The local CPU-hosted CUDA 12.9.86 compiler emitted real SM90a pair and quad images, each with 168 registers/thread, 156,672 B dynamic shared memory, zero stack or spills, seven activation multicast sites, and the same 592–598-instruction residual loops. An eight-way diagnostic cubin has the same resources and loop shapes and would reduce rank 3’s 16K source boxes to 624 MiB. Its extra synchronization and GPC placement need hardware measurement. Four-way has three cross-CTA stage releases per leader, up from one for a pair. At equal useful work this changes the aggregate remote stage arrivals per logical CTA from 1/2 to 3/4. Giving up four CTAs to launch 128 four-way CTAs in place of 132 pair CTAs can cost at most one additional equal-duration persistent wave at 16,384 local rows. A different grid can also group heavier residual tiles on the same CTA. On the archived 12,288-token draw, the critical CTA’s issued tensor rows grew 9.4%–16.4% across ranks despite the one-wave bound. At 16,384 tokens the change ranged from −9.2% to +4.3%. V274 retains the matched grid. Incidence of this fallback on the target H200 is unknown. [Residency sensitivity and legal histograms](grid_haircut.json)

The official export is 408,704 bytes against base 297e54fd, with 896 bytes of headroom. The complete patch and the 5,010-byte incremental delta apply strictly and reverse to their respective input trees. The CPU callback replay matched 2,072,064 BF16 words and 1,048,864 routing-map entries. End-to-end speed, device parity, time to first token and runtime memory remain unmeasured. A separate scheduling experiment grouped expert M tiles by their actual issued WGMMA width, descending. With cyclic assignment the difference between the heaviest and lightest CTA is at most 256 issued rows. Fractions of the same width at the end of one grid wave continue into the next, and the difference between any two cyclic sums telescopes to at most the largest tile. Across all eight archived ranks, a 128-CTA quad grid in this order would have 2.6%–5.1% fewer critical issued tensor rows than the 132-CTA native-order pair grid at 12,288 tokens. The 16,384-token range was −11.3% to +0.76%. It needs an expert lookup for reordered tiles and a cache-locality measurement. A periodic job rotation raised the critical row count by up to 11.5% on the 16,384-token draw. Both alternatives are host simulations.
