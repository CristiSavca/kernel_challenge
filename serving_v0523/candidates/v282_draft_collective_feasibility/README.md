V282 evaluated a different ownership scheme inside the five-layer draft. Each rank owns complete request blocks and computes the dynamic depthwise convolution, residual and RMSNorm on its rows. Complete blocks retain the trained causal predecessor at every tap. An all-gather provides the full pre-convolved inputs for column-parallel QKV and gate/up. A reduce-scatter hands completed row-parallel O and down projections back to their owners. The final vocabulary projection still needs all prediction rows on every shard.

Leaving the first filter replicated removes one gather and brings wire volume to 35 and 70 MiB at the two higher loads. Either ownership schedule still reads 320 MiB of filter weights on each active owner. V123 needs 40 MiB per rank for the same full-K arithmetic and adds 8.75 MiB in coefficient gathers at 32 users. An owner can save elementwise normalization work, but this comparison provides little case for shipping a second ownership system. A CPU replay ran the actual unwrapped V279 grouped-convolution source through ten sublayers and compared 610,560 BF16 words for owner-local and replicated inputs, coefficients and residual states. It used the same simulated FP32 rank sum in both paths. The pinned native all-reduce can dispatch to a custom backend, while native reduce-scatter calls PyNCCL or the device group. A separate negative control changed 1,002 of 2,048 BF16 outputs when the rank-sum tree rounded in BF16. The deterministic-inference fallback performs a full all-reduce followed by a narrow. There is genuine independent work in each draft sublayer. Its post-convolution coefficients depend on the incoming normalized hidden state and can be calculated while attention or MLP runs. Splitting the currently combined coefficient matrix would add ten GEMM launches per pass and move up to 160 MiB of replicated weights off the dependency path. Scaling the archived 64 MiB H200 pooler time by one quarter for a 16 MiB post bank gives roughly 0.063 ms at one user and 0.087 ms at 32 users for all ten projections. The illustrative speed factors under perfect overlap are 1.0032× and 1.0009×. This is a cross-kernel sensitivity estimate. V123 already distributes those banks.
