# V77 independent review

Verified the frozen export `05426d8be9e013fa73f24f10a72958a3ca4b74b942a770756f4b52126931651a`. Two sections differ from V76, the Humming stage and its environment switch. The 147,143-byte payload retains the same 28 allowed paths. The longest addition is 106 bytes. All changed Python sources compile.

Each `(expert,tile)` block counts all later experts plus the current expert's remaining routes. Subtracting that count from the fixed slot total yields the first live output row for this tile. An inclusive scan identifies the consecutive destinations in original slot order. Distinct tiles own disjoint destinations and the old Humming layout still ends at the fixed arena size. One block per expert writes its offset. Expert zero owns the local ID array, remote row-map entries and final end offset. Only live rows write staging data. The subsequent scaled SiLU reads keys from the first live offset and the weighted finalizer resolves valid original slots through the inverse map. These operations preserve the existing GEMM and precision boundaries. Hardware/shape selection and the original fallback remain available.

An independent stable-sort oracle covered 840 cases, 429,320 input slots, 224,872 live rows and 80,352 CTA assignments. Cases included single-expert concentration, empty ranks, a lone final live slot, non-power-of-two sizes, negative and out-of-range IDs. A second execution of the candidate source suite passed 192 staging cases, 48 end-to-end finalizer cases and 55,733 BF16 route-value comparisons.

The optimization removes one launch for each eligible layer and avoids the serial stable sort. It duplicates metadata reads across CTAs. At 32 experts and 2,048 slots, 512 CTAs request 1,048,576 logical route IDs before expert-map lookups. Cache can serve many of those loads. Highly skewed routing can also reduce parallelism of the live activation copies. Neither the CPU checks nor source review measure these costs or compile the Triton kernel. H200 JIT, changing-route graph replay, per-step timing, official output correctness, memory and TTFT remain open.
