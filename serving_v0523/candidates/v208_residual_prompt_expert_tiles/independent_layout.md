# Independent V208 live-row review

The emitted 32- and 96-row operations bind the first 16 and 48 FP32 accumulator words per lane. The 176-row operation binds 88. Humming exchanges the usual matrix labels here: the native fixed 64-axis represents output channels, and the variable axis represents token rows. In the SM90 `m64nNk16` accumulator layout, every consecutive four-word group extends the variable axis by eight rows. The independent check inverted that ownership for both output bands and both warpgroups, then tested all 176 possible live-row counts. Every occupied token/channel landed in an initialized register. It checked 3,987,456 live coordinates. The W13 writer masks the row before loading and writing its gate/up fragments, and W2 retains the vendor grouped writer and its expert-local end bound. The published grouped scheduler locates an expert using rounded-up tile counts, then forms both `current_shape_m` and `m_offset` from that expert’s packed row prefix. Their difference is its live suffix. Crossing an expert subtracts a multiple of 176 from an aligned cursor. Crossing an empty expert advances only the expert ID. A separate prefix-sum reference checked 59,400 tile seeks in 3,375 boundary-heavy expert distributions, including 47,430 crossed boundaries.
