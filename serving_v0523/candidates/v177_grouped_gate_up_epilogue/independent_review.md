# Paired W13 projection

The production four-dimensional TMA descriptor packs each matching pair of logical 128-channel segments into one native 256-channel shared K slab. Our host C++ fixture executes the actual descriptor builder with a checked driver stub and verifies 3,538,944 packed address and destination comparisons across the first and last K tiles and expert banks. Both N boundaries are multiples of the vendor's 64-column by 16-K packed block. The eight-group native WGMMA consumes exactly the gate or up packed values and scales for each output column through its existing dequantization and full K traversal.

The native writer first materializes BF16 projection fragments. A gate int4 at shared row S is paired with an up int4 at S+2M, with the 128-byte swizzle evaluated separately at each address. The test independently inverts Humming's ordinary logical C writer to populate these banks. It then executes the production fragment reader, scale indexing, row mask and compact output stores. It covered 17,018,880 output values, every BF16 bit pattern in each input band, 10,861,824 untouched guard words, tile heights 136/152/176, and widths 128/384/4096. Scale rounding is exercised before SiLU and the final BF16 store. The CUDA multiply and exponential are represented by host binary32 operations, so this fixture establishes addressing and boundaries; CUDA code generation and numerical behavior require separate evidence. [Source fixture](independent_epilogue.py) · [Replay](independent_epilogue.json)

The grouped scheduler only issues nonempty tiles and supplies the exclusive expert end along with the cohort-relative row start. Both native caller and launcher use corresponding cohort-relative input, output, route IDs and offsets. The fused output has I elements per row and stays separate from the gathered input while W13 is active. W2 reuses that old input allocation only after every W13 cohort has enqueued on the same stream. Vendor math-thread barriers surround the local epilogue; the new path introduces no inter-CTA rendezvous. Disabling the local paired specialization leaves the native expert return order and all-rank communication choices intact.

On one archived H200, 16,384 prompt rows with 16,224 selected local routes required 7.19–8.05 ms in an older complete expert path. An isolated uniform dense reference ran in 2.64–2.74 ms; per-rank routing, bounds and output work prevent directly applying that figure to V176. Removing W13 materialization eliminates about 507 MiB of nominal BF16 tensor writes and rereads at that geometry. At 4.8 TB/s this volume would take 111 microseconds.
