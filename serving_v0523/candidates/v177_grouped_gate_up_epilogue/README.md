# V177 paired gate/up epilogue for grouped prompt experts

At 16,384 routed rows with 4,096 hidden and intermediate channels, V177 removes a 256 MiB gate/up write and the following 256 MiB read on each eligible rank and layer. It reduces the two projection workspaces from 384 to 256 MiB and removes one activation launch per nonempty window. The theoretical transfer equivalent at 4.8 TB/s is 0.112 ms per layer. The actual time depends on L2 hits, tensor-core occupancy and achieved HBM bandwidth. V177 has no physical H200 measurement. Its parent V176 is unmeasured; the scored ancestor V64 reached 1.4119× overall. [Work model](traffic.json) · [V64 score](../../runs/abd217baf0ed49fd.json)

The gate and up projections occupy separate halves of the same packed W13 bank. A four-dimensional tensor map delivers matching 128-channel bands from those two halves into one native 256-column Humming tile. A second map does the same for E4M3 scales. Humming performs its ordinary full-K WGMMA and converts the FP32 accumulator into its BF16 shared-memory epilogue. Before that tile is released, each thread reads its matching BF16 fragments, applies the original per-expert scale and BF16 rounding to gate and up separately, then evaluates the original FP32 SiLU/product and stores a BF16 activation. W2 reuses the input gather buffer once all W13 launches on its stream have completed. No weight copy is required. Route sorting, V169's selected widths and all W2/finalizer arithmetic are preserved. The optional adapter builds only for the compatible Hopper grouped BF16/NVFP4 ABI in Humming 0.1.12.
