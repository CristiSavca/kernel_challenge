# Draft cache address ownership when composing V253 with V229/V248

V253 translates each target iteration's slots through the draft sliding-window address space once. For these context writes, `_context_kv_pool()` returns the physical BF16 leaf also registered as the HiCache `DRAFT_SWA` sidecar. Running the broad branch's unmodified projected-prompt recovery against that ownership fails on both 1D prompt writes and 2D accepted-prefix writes. [V253 ownership delta](../v249_private_draft_swa/delta.diff) · [Runnable adverse replay](broad_writer_check.py) · [Results](broad_writer.json)

| V248 `dflash_worker_v2.py` line | Address consumer | Required binding |
| --- | --- | --- |
| 2,702; 2,888; 3,550 | Mixed prompt/tail settlement, ordinary prompt, standalone verification | Preserve the new draft sliding-window `KVLocPlan.write_ids` query. Ordinary request/slot tables continue to hold virtual rows. |
| 2,132; 2,222; 2,241 | Prefix-valid recovery, flat sequential recovery, fused materializer callback | V249/V253 already changes these three sites to the context pool. This includes the fused callback's flat and prefix setters. |
| **2,194–2,198** | `_append_paired_prompt_kv` per-layer writes when fusion is disabled or fails partway | Bind the callback's five-layer destination to `_context_kv_pool()`. The outer SWA wrapper's flat setter requires an explicit `swa_loc`; its class has no prefix-valid setter. |

The factory's layer map assigns all five draft layers to `swa_kv_pool` with identity layer ordinals. The V229/V248 stacked prefill projection helper only computes K/V and invokes the worker's `write_layer_kv` callback. It has no independent raw-cache scatter. Target FP8 `muse_verify_fp8_store` separately pairs the target's own SWA leaf with `write.swa_loc`. Native BF16 FA binds the wrapper's layer K/V buffers and the SWA locations derived from its per-step plan. These target and attention calls keep their own addressing. [V248 source](../v248_shared_verify_raster/patch.diff) · [V253 factory and context owner](../v249_private_draft_swa/delta.diff)

The CPU test compared the actual original helper with its one-line ownership correction across two mutable, nonidentity full-to-SWA maps. It used real plan translation, the registered HiCache sidecar, full-row and ragged accepted-prefix writes, and deliberately failed the fused callback after layers one or three. Twelve unadapted calls failed. Four unadapted calls completed the fused route without touching the defective recovery; all sixteen corrected scenarios passed. The full BF16 bit comparison covered 545,600 array cells, including guard rows, 9,600 live cells and signed zero. The same test exercised the actual V256 implementations at worker SHA `daf33bdbc9d2d043d9ffdd37ef19455c571ade4efb1a4573dabef8250c2d4b88`. Device kernels, graph replay, and service timing remain unmeasured. [V256 exact-source result](../v256_window_backed_mixed_serving/paired_store.json)
