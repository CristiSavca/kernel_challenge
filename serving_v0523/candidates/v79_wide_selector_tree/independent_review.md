# Independent review of wider DFLASH verification

Reviewed frozen SHA-256 `3b845bbbed63c52bfc3f8f264d0e233feb74d10e8a14cff803ab13bfc87ccac2`. It matches the isolated official export. Two sections change from V76 across the same 28 allowed paths. The payload contains 144,189 bytes, its longest added line is 106 bytes and all 25 changed Python sources compile. `--speculative-num-draft-tokens` clears all 76 fixed-flag patterns in the judge template.

**Ownership and coverage.** Each CTA band owns different query/head pairs and reads the same ordered KV partition. The per-partition store and merge use the common padded band stride. A width-12 target with GQA8 has 96 active pairs in two 64-lane bands. Extra lanes have dedicated scratch and cannot address live queries or output. Tree bit masks represent all 16 nodes in the widest eligible tree. The live target predictions, ancestry visibility, greedy accepted-path walk and KV slot permutation are unchanged. A non-tree request uses its ordinary linear positions and masks.

**CPU checks.** The [source harness](cpu_check.py) executes the actual host launcher, partition and merge with bounds-checked CPU pointers. Across 96 dense-reference cases the maximum relative L2 was 0.001776. Coverage includes W8/12/16, GQA4/8, one and two KV heads, full/SWA, per-head descales, linear/tree, nonuniform prefixes, shuffled pages and padded/zero-query requests. All 32 W8 outputs matched V76 bit for bit in this harness. The widened tree passed 400 proposals, 6,400 accept/slot cases, 202 graph metadata resets and 34 backend eligibility cases. The earlier fixture's synthetic 53-slot request table was expanded to fit the generated prefixes plus the larger width. The tests emulate Triton and use FP8-representable inputs. GPU compilation, FP8 tensor-core rounding, memory and graph replay need an official check.

**Serving implications.** Width is fixed per launch. SGLang updates both draft convolution block sizes, selector buffers, target graph rows and reserve sizes when resolving the command-line override. The released draft config reports training width eight. Acceptance past eight positions is unmeasured. At 32 users, W12 and W16 exceed the existing 2,048-route grouped expert bound for top-8; the indexed Humming path takes over. At max batch 32, W12 adds 98.66 MiB and W16 adds 197.31 MiB to the startup dense logits tensor alone over W8, given a 202,048-token vocabulary. The second band reads the same KV prefix and the wider pass performs more transformer work per step. Only higher measured committed-token throughput with the official limits satisfied would justify the wider launch.
