# Independent continuation and mixed admission review

The new pure-TP reservation occurs after normal chunk initialization and the existing shortest-prefill policy, immediately before the native chunk adder. The rank vote compares both signs of the seven scalar decisions. A local geometry, memory or sampling veto therefore leaves the original cap in effect on every rank. The V160 admission later verifies actual request identities, allocator capacity, native sampling, pool ownership and bucket cost independently; a late veto can yield an ordinary, shorter continuation. The reservation stores one scheduler-round token cap and allocates no KV itself.

The independent replay executed the production budget function through 14,000 entire synthetic prompt sequences using the archived graph buckets, 77,278 decisions and 3,493 eligible reservations. The later admission accepted 1,745 and declined 1,748. Every prompt row remained covered exactly once and in order. At constant capacity each sequence retained its original number of prompt forwards, and total static prompt/mixed rows stayed within the native prompt sequence's budget, even with varying decode widths and cohort counts. Separate fallback decode work is outside that count. A later change in memory pressure, other admitted work, or rank timing can change an observed schedule. No H200 time was inferred.
