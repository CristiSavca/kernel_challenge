# H200 timing context for the prompt expert epilogue

The archive contains a matching-shape whole-expert measurement on a single H200. The test used 16,384 BF16 input tokens, 16,224 local routes, 32 local experts, top eight of 256, 4,096 hidden and intermediate channels, and synthetic NVFP4 checkpoint weights. Across four runs of stock Marlin, the expert call took **7.188–7.394 ms**. The final run also measured V40 at **6.617 ms** with CUDA graph replay and the dense384 route at **5.831 ms** eager. Each includes both projections and the operations between them. The archive provides no isolated activation interval or steady-state Humming grouped projection time. [Example H200 result](../../../experiments/modal_serving/20261113T065259Z/result.json) · [Run manifest](../../../experiments/modal_serving/20261113T065259Z/manifest.json) · [Other H200 samples](../../../experiments/modal_serving/20261113T045613Z/result.json)

The archived dense reference took **2.643–2.698 ms**. Its paired result records 507 rows per expert. The retained worker constructs grouped BF16 inputs and dense BF16 weights and runs W13, SiLU, multiplication by up, and W2 separately for each expert. This removes NVFP4 dequantization, route gathering and finalization and keeps the activation itself. Subtracting its elapsed time from Marlin cannot isolate V177's saved work. The retained worker has a later source digest than the archived run manifest. [Worker routine](../../../tools/serving_moe_ab_worker.py) · [Second independent H200 run](../../../experiments/modal_serving/20261113T055610Z/result.json)

At the physical example's 16,224 routes, the removed gate/up round trip is **507 MiB** of logical tensor traffic per rank per layer. At the published 4.8 TB/s peak, that quantity corresponds to 0.11076 ms, or 6.867 ms across 62 identical layers. This conversion assumes HBM service at peak bandwidth. Actual HBM traffic, cache reuse, launch overhead and overlap could each change the observed effect. [V177 traffic formula](../v177_grouped_gate_up_epilogue/work.py) · [Published hardware assumptions](../../../muse_moe_w4a16/TASK.md)

This opportunity applies during long prompt processing. One archived eight-H200 16-user session recorded 75 long prompt calls covering 1,228,800 newly processed tokens. Those scheduler counts establish reach. The separate V43 forced-Marlin 62-layer profile was captured during graph warmup and compilation before a startup error. Using those figures as steady-state cold-request latency would inflate the estimate. The scoped standalone expert problem times up to 256 input tokens, and the prefill-layer problem publishes whole-layer theoretical floors. Neither provides the missing Humming activation interval.
