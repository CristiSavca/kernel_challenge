# V164 sparse expert decode and prompt exchange

V164 combines V161’s Hopper tensor-memory transfers for low-row target expert verification with V163’s sparse exchange of long-prompt expert inputs. The frozen official patch is **140,262 bytes**, SHA-256 `a8b11f1460005a0290dfef86e97a8f043c016ac8b4540f1f423cd7cdd6a6ba04`. Physical H200 agreement, memory, latency and throughput are unmeasured. The strongest measured four-load serving score remains V64’s 1.4119×. [Official patch](patch.diff) · [Frozen flags and reconstruction](validation.json) · [Scored V64 reference](../../runs/abd217baf0ed49fd.json)

| Execution phase | What runs on the challenge geometry |
| --- | --- |
| Target verification | V161’s TMA-enabled expert pair handles eligible banks up to 256 routed slots, including width-eight verification at one and four users. The medium route-pair path handles 257–2,048 slots. Native indexed and vector fallbacks remain available. |
| Long target prompt | At 8,192 or more sequence-parallel token rows, ready Humming banks exchange the token rows needed by destination experts. If the shared vote or buffer-size test declines, ranks gather the dense inputs. V135’s bounded, scaled-SiLU grouped computation and deferred down-projection scale operate on either representation when available. |
| Short target prompt and draft | V161’s ordinary target expert entry stays in place below the prompt threshold. The launch requests Marlin for the draft. Its DFLASH proposal, width, acceptance and verification are inherited. |

Use the exact five launch flags in the manifest. The target expert and prefill attention defaults are inherited from V161. The sole extra switch is the bare `--muse-sparse-prompt-exchange`, which defaults off. [Flag manifest](validation.json) · [V161 dispatch](../v161_tma_expert_channels/README.md) · [V163 transport](../v163_sparse_prompt_exchange/independent_review.md)

The combined change maps original token positions to the compact receive buffer before each grouped gate/up projection. Each prompt window slices the row map at its own begin/end while retaining the packed input buffer’s base. The original route IDs and scores still identify output rows and the scales used by the finalizer. If the transport’s exact local route count fits the existing workspace limit, the entire local batch is one valid window. For a skewed rank that exceeds it, the existing 128-token tile counts split the work into bounded windows. With the new switch disabled, the parent’s grouped window planner and dense gather execute normally. ## Evidence and controls

- **Prompt correctness.** The merged source passed 864 replay and late-hook checks across 664,128 token rows, including 36 multiwindow calls and 456 scaled finalizations. Each output matched the independent CPU BF16 reference. An additional EP8 fixture compared 3,932,160 elements with cap±1, hot-rank and empty-route cases. CPU Gloo exercised all-to-all transport on 672 rank cases across TP2, TP4 and TP8. Physical H200 kernels, NCCL and CUDA graph capture still need a serving check. [Graph and finalizer receipt](integration.json) · [Transport receipt](transport.json) · [Window receipt](independent_windows.json)
- **Decode dispatch.** The merged source passed all 54 setup cases, 72 dispatch cases and 768 tensor-map encoder calls. The expert TMA header, vector fallback, host setup and dispatch bodies match the ones checked on the V161 source. The published SM90/SM90a compilation evidence applies to the identical CUDA sources. [Dispatch](dispatch.json) · [Encoder checks](descriptor.json) · [V161 machine-code evidence](../v161_tma_expert_channels/sm90.json)
- **Serving comparisons.** V164 with all five flags versus V161 with its four flags isolates the prompt exchange on the same target expert and attention lineage. V164 with the prompt switch omitted provides the same direct control in a single patch. V161 versus V153 isolates the low-row TMA change. V163 versus V64 isolates the exchange with V64’s grouped prefill implementation. V164 versus V64 combines several inherited changes, so a result from that comparison cannot attribute their individual effects.
