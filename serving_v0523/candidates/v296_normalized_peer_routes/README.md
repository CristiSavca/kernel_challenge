# V296 publishes normalized prompt rows and routing metadata together

V296 combines V293’s direct RMSNorm destination with V295’s peer routing packets on V291. An eligible rank normalizes its pooled input directly into the current symmetric buffer and publishes the BF16 values, original FP32 scores, original int32 expert IDs and eligibility marker with one peer barrier. Other ranks consume the exact routing words and required expert input rows. Two banks allow the next publication to retire the previous bank. [Serving patch](patch.diff) · [Changes from V295](delta.diff)

A rank can use the native normalization module while another writes directly into its buffer. If any rank vetoes the packet protocol, a rank that already normalized into the slab clones those rows on the publishing stream while it still holds the lock. A locally vetoed rank with deferred normalization runs the native operation once. The fallback gathers the original routing data and supplies ordinary normalized inputs to its original expert path. Captured private helpers that have since been replaced receive their original plan and normalized input. - Two independent TP4/TP8 Gloo fixtures each exercised 276 rank-calls, 861,584 score/ID pairs and 7,813,888 BF16 activation words. The checked CUDA-body fixture took 101 direct and 175 ordinary normalization paths. The independent model-entry fixture chose 126 direct, 24 functional and 126 original-module calls.
