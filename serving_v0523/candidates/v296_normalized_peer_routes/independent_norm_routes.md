# Distributed normalization and fallback

Across 276 rank calls on TP4 and TP8, each token shard passed through normalization exactly once. The combined model took the direct path 126 times, invoked functional RMSNorm 24 times, and dispatched the norm module 126 times. A different rank had a norm hook in each epoch, and selected epochs also installed a single-rank expert hook. Every branch matched 861,584 route score/ID pairs and 7,813,888 BF16 grouped or fallback activation words, including 22 empty local receivers. [Case counts and source hashes](independent_norm_routes.json)

On 26 local writes, another rank vetoed the early route packet after the local rank had normalized its own rows into the shared bank. The test immediately filled the retired bank with a sentinel before any fallback gather. All 26 saved copies remained valid. A deliberate substitution of a live bank alias for the saved copy caused **17,088 incorrect BF16 words** in the first four-rank asymmetric expert-hook fallback. [Negative control](independent_norm_alias.json)

The replay executes the staged SP model entry, admission, routing, grouped-input preparation and fallback on Gloo process groups and mapped CPU slabs. Normalization executes the staged CUDA routine as a host coroutine against a separate host implementation of the pinned ATen reduction. CUDA stream events, final all-reduce and Humming math are modeled. Run `independent_norm_routes.py STAGE` with CPU PyTorch, NumPy and a C++20 compiler. Add `--alias` to run the failing control. [Replay](independent_norm_routes.py)

A further 12 rank calls replaced a single rank’s grouped helper after norm admission and before legacy execution. Both replacements saw bit-exact normalized input and the original five-entry plan. Across both process groups, 43,152 route pairs and 207,104 activation words matched, with one normalization per rank. Run the same script with `--late-helper` to exercise this case.
