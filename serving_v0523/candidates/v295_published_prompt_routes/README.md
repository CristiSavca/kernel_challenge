# V295 publishes prompt routing with the expert inputs

V291 gathers route scores, expert IDs and a rank eligibility vote separately in each sparse prompt layer. Each rank also publishes its activation rows to its peers. V295 appends the exact score bits, IDs and vote to the activation bank. Peers read both after the existing publication barrier. A 62-layer pass that qualifies throughout removes 186 separate route collectives. The established route ordering, grouped expert computation and final output reduction still execute. [Standalone patch](patch.diff) · [Change from V291](delta.diff)

The change exchanges collective overhead for packet packing, mapped peer reads and a transpose. At TP8 and 16,384 prompt tokens, each rank logically reads 917,616 remote routing bytes per layer, 84 more than V291. At the 16,640-row graph ceiling, the two banks together add 272 KiB of slab space per rank. The four-word vote trailer also keeps the normal packet width aligned to the pinned framework's 16-byte copy path. A rank veto restores the original route and activation operations. Allocation and registration failures try the legacy two-bank, single-bank and native paths in order. The distributed host replay matched 861,584 score and ID pairs and 7,813,888 BF16 activation words across 276 rank calls. Accepted calls used one publication barrier and zero separate routing collectives. Actual Breakable capture stubs performed no publication. Replays covered local hooks, remote vetoes, bank reuse and wide dtypes. The stream model checked 7,343 ordering requirements and detected missing edges in each ablation. The 401,651-byte export reapplies to the pinned SGLang base and reverses cleanly. The full diff and changed files meet the published structural rules. On the archived 32-user schedule, 150 size-eligible calls would remove at most 27,900 separate route collectives. A 5% raw throughput improvement at that load would require a net 1.56 ms per eligible layer. No H200 throughput, token agreement, peak memory or TTFT was measured for V295.
