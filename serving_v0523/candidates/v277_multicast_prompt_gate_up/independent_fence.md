# Shared-memory lifetime in the persistent grouped prompt kernels

The pinned Humming storage union puts the reduction scratch at the first A tile's address for these configurations. The old W2 multicast epilogue waited only for the leader's consumers. A fast leader could overwrite a follower's first output fragments while that follower still read them. The same dependency applies to W13's paired gate/up output.

V277 W13 MC4 and V274 W2 MC2/4 use one remote arrival from each follower's producer lane zero after its local math wait, load-thread rendezvous and generic-to-async proxy fence. The leader expects its 256 local math arrivals plus one per follower, hence 257 or 259. Nonleaders keep 256 local arrivals. Subsequencing is enforced by the first A multicast each job requires before its consumers can complete another epoch. Zero-job clusters have no producer waits, the seed supplies the first nonempty epoch and the last completed job has no following producer wait. The uniform block barrier and cluster barrier at kernel exit protect the final DSM lifetime.

W13's gate and up shared loads occur before its global store and the native epilogue's closing math-thread barrier. Full and residual paths then release the epilogue. For the ordinary K ring, W13 reads A directly at the fourth K16 instruction after the third K16 release. With four stages, the producer can refill a physical stage only after every rank has reached the *next* stage's release. Both W13 WGMMA paths drain each K16 before proceeding. W2 delays its release until the last K16. W13 construction requires four stages.
