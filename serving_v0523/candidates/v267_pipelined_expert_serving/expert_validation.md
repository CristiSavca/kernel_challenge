# Integrated prompt and decode expert checks

V267 and V248 matched on 126 paired rank cases through the normal sequence-parallel prompt model entry using real Gloo groups of two, four and eight processes. The test compared 4,747,168 BF16 output words, including strided or padded inputs, zero-local routes, concentrated routes, an int64 fallback and an opt-out by one rank. The compact count and placement path ran with CPU stand-ins for Triton, peer buffers and expert arithmetic. Rank-local opt-outs took the paired native collective path. The same expert objects then handled small target verification after a 16,640-row prompt with mixed, repeated and missing routes. Four successive calls per rank exercised direct token-major W13, a rejected descriptor followed by native repacking, a skewed single-expert route and an all-remote call. The ordinary W4A16 entry ran its grouped planner, called W13 and W2, finalized the weighted partial and performed the fixture's cross-rank reduction. V267 matched V248 across 56 paired rank calls and 6,944 BF16 words. Re-entering the prompt path on the same layers with changed inputs and routes matched another 798,720 BF16 words. It checked 27,694,080 live BF16 values, 12,143,616 guard words and 16,380 tensor-copy coordinates. CUDA TMA and WGMMA hardware remain unmeasured for V267.
