# V267 identified a rounding change when splitting attention output reduction

**Hold V267 out of the private queue.** At TP8 and 8,200 prompt rows, reducing two 4,096-channel BF16 stripes gave 159 different values from reducing one 8,192-channel tensor on Gloo. The row count divides evenly across eight ranks. Across 12 TP4/8 native-width comparisons, 25,679 of 1,074,921,472 results differed, with maximum absolute error 0.09375. Message width can affect the order in which ranks contribute to a sum. The full-width output reduction is restored in V268. [Native-width results](collective_shapes.json) · [Reproducer](collective_shape_sweep.py) · [V268 control](../v268_native_sum_expert_serving/README.md)

An integrated attention test traced all 1,556 differing owner values to the reduction across GPUs. The QKV results and local output-projection GEMMs matched the control. A fixed 64-output synthetic head chose the same output on every one of 24,576 rows. A two-output head with its competing score between the two observed feature values changed its greedy choice. H200 generated tokens have not been tested. [Paired attention and logits](attention_pipeline.json) · [Test driver](attention_pipeline_check.py)
