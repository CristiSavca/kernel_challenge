The prefill worker now accepts the already projected, rank-local K/V values from the target output marker. A 112-case paired CPU replay compared the entire physical pool, including untouched capacity and slot zero, against the original normalized-feature path. It exercised the pinned prefill entry, request position calculation, two KV-plan translations, 5-layer fused helper and sequential layer fallback, native per-head RMSNorm/NeoX RoPE and the MHA pool’s physical-write check. The synthetic model used two heads of dimension eight, partial rotary width six, three distinct warm prefixes and shuffled physical destinations. All 2,042,880 BF16 values compared equal across the paired runs. The producer marker and TP environment were injected at the target worker boundary. CUDA’s fused norm/RoPE and terminal physical scatter were emulated on CPU. [Runnable fixture](worker_check.py)

The partial-write case deliberately fails immediately after physically writing the third layer. The sequential path then rewrites all five at the same physical slots from the original raw projections. All bytes match the same native recovery sequence starting from ordinary normalized features. The separate fused comparisons retain their fused numerical boundary. The test poisons trailing replay rows with NaNs and checks that no padding touches the pool. It also checks that the input carrier stays intact, the projected route never calls `torch.mm`, and the cold route leaves the projection scratch unallocated. Warm calls reuse the existing K/V scratch. Five invalid marker/shape combinations reject the call, and the real worker withholds its paired helper for non-unit model V scaling, LiLiCorr, capture, log-probability or requested external hidden states.
