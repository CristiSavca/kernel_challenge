# Independent FP8 slot and attention replay

The fixture invokes the production BF16 query conversion, direct K/V producer and prefix completion, then compares them against a separate physical-slot oracle. A base allocation holds strided K and V views, including a case where both arguments alias the same BF16 tensor. Positive cases include fresh prompts, reused full prefixes, translated and independently fragmented SWA slots, and 0/31/2,047 left windows. The references apply the stock in-place scale divisions in BF16, cast both operands to FP8, then write and read arbitrary distinct physical slots in logical request order. Scaling by the actual per-head FP8 descales, applying a nonzero soft cap, and computing grouped-query attention in float64 matched on 3,072 outputs. Direct attention and physical-table reads returned identical bits across 11,593,728 K/V bytes. Four signed conversion cases also matched over every BF16 storage encoding, yielding 262,144 FP8 comparisons.

Observed declines cover a padded query passed before narrowing, Full graph execution, synthetic capture warmup and eager scheduling without the required host mirror. All four returned before modifying source tensors. The positive live Breakable cases use the true row count. The physical scheduler and complete callback are exercised separately in the authored ownership and replay fixtures. This independent CPU calculation checks the mathematical operands and the visible causal window. Actual FA3 can select a different partition or reduction order on H200.
