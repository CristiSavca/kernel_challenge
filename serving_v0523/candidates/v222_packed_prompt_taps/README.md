# V222 writes cold-prompt taps into their final local graph buffer

On the archived 16,384-token prefill graph at TP8, V219 reserves **1,536 MiB per GPU** for a final hidden tensor and five DFLASH target taps. Each GPU produces 2,048 rows because the Muse transformer shards prompt tokens across ranks. V222 reserves **192 MiB per GPU** for these same outputs and writes the taps directly to their final positions. This reduces named buffer capacity by **1,344 MiB per GPU** and removes two copies of the five taps. Physical peak memory, first-token latency and serving throughput have no H200 measurement for V222. V64 remains the official four-load result at 1.4119×. ## What runs on a cold prompt

The registered multimodal model calls the Muse text wrapper. Its Breakable prefill backend captures the transformer body and replays the logits and draft-context tail eagerly. The parent allocates six BF16 output leaves at the largest global token count. The producer returns a local token shard for each leaf, the backend copies those leaves, and the eager tail concatenates the five raw taps for the draft FC. In the archived V41 trace, 775 prompt forwards report CUDA graph replay and 273 use the full 16,384-token chunk. Its 74 graph keys include four sizes that need padding up to a multiple of eight. [Source and trace audit](independent_audit.md) · [Trace and checksum](independent_capacity.json)

V222 binds a 32 MiB final-hidden destination and one 160 MiB packed tap matrix before capturing the first shape. Each of the five producer layers casts its own FP32 residual directly into its columns in that matrix. The backend and live wrapper still expose five separate indexed tensors. The eager tail uses the packed matrix only after checking all five storage views, shapes, dtypes and lazy view flags. For a full chunk the backend’s tap copy and the eager concatenation previously each read and wrote 160 MiB, for 640 MiB of logical data movement avoided per rank. At the H200’s published 4.8 TB/s peak this volume represents approximately 140 µs per full chunk, or about 0.63 ms for the public 74,160-token first-prompt example. These figures measure traffic exposure. The full-width 40,960 → 8,192 draft FC, native normalization, KV projection, cache addressing and all target layers still run. ## Runtime and compatibility

The option applies to the native Muse sequence-parallel transformer in the ordinary single-stage DFLASH Breakable prefill backend. Each graph key views the buffer at its own ceiling-divided local row count. Hooks installed before graph capture use the parent representation. A live wrapper hook sees separate, contiguous, offset-zero leaves, including one-row keys. Replaced and reinterpreted leaves take the native packing path. An allocation failure on one rank can use the parent’s local layout while peers use the packed view. The following distributed projection still receives the same local sequence rows. On recapture a compatible session reuses the raw backing. The interactive generation inputs never persist as reusable model results.
