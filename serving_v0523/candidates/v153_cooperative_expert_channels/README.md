# V153 cooperative expert projections at low routing density

V153 gives eight warps the 128 output channels that two warps compute in V147. At one native request, uniform distinct top-eight routing yields about 230 useful blocks per projection on each rank. This change exposes about 1,837 productive warps across the GPU, up from 459. Each warp computes its own outputs through the full K dimension in the original order. The official 120,121-byte patch has SHA-256 `ca8b5aa125f47c86d7f20cf4c2a941d8498c962f28ac62d85b684509fa35cc0a`. Physical H200 latency, serving agreement and score remain unmeasured. [Official patch](patch.diff) · [V147 delta](delta.diff) · [Manifest and four inherited flags](validation.json)

Within each block, the warps copy a chunk of eight K slices of the resident NVFP4 weights, E4M3 scales and BF16 activations into shared memory. While the warps consume that chunk, 16-byte asynchronous copies fill a second buffer. A warp owns one 16-channel tensor-core fragment at each step. Rotating its fragment index across groups of eight lanes assigns distinct shared-memory banks while preserving the row mapping of the tensor-core instruction. One source warp stages each of the eight activation rows, and an inactive route supplies zero valid bytes to the copy. The gate/up BF16 rounding and SiLU, the down-projection BF16 output, and the parent finalizer retain their original operations. The lookahead estimate caps the useful blocks at the four-block-per-SM register limit. At one user V147's one-slice W13 and two-slice W2 lookaheads each cover about 0.50 MiB across the useful blocks. The cooperative kernel also trades register-resident operands for shared traffic and adds 33 block rendezvous through a 4,096-wide projection. Timing determines whether the larger lookahead pays for that work. At 16 and 32 users the existing medium-density kernels run. [Executable geometry model](work_model.py) · [Results](work_model.json)

NVCC 12.9.86 compiled the actual sparse and medium TVM FFI wrappers for SM90 and SM90a. W13 uses 57 registers per thread and 42 KiB of shared memory per block. W2 uses 58 registers and 24 KiB. Both compile without spills. In the assembled eight-slice steady loop each warp has 987 static instruction sites for W13 or 681 for W2. Four warps now share the output work of one previous warp. The original low-density fallback, medium-density projections and route planners retain all 8,320 machine instructions exactly on each target. The production CUDA-body simulator checked six geometries through 4,096 × 4,096 and two reduction-order cancellation fixtures. It executed 2,097,376 live and 235,808 zero-fill vector copies with both immediate and delayed completion, and 2,529 whole-block rendezvous. The inherited adapter passed 72 startup and 81 dispatch cases. The compiled host launcher passed 512 cases covering each eligible and fallback address combination. A phase uses the original V147 projection whenever its activation, weight or scale base lacks 16-byte alignment. The official patch and parent delta both applied forward and in reverse.
