# V224 packed prefill on the V219 serving stack

V224 integrates three changes to the work before the first token. V219’s speculative decode and verification paths are included. Archived phase replays put the four-load score at only 2.37–2.48× stock even with instantaneous generation after the first token when cold latency is held fixed. That is a counterfactual for the archived traces. V64 still holds the measured four-load result of **1.4119×**. The buffer reduction describes these six allocations. CUDA graph pools and simultaneous allocations determine measured whole-model peak. The attention change can change native FA3 tile or split choices. FP64 replay establishes equivalent logical attention. H200 measurements must establish generated-token agreement and throughput.
