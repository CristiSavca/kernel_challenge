# V123 rank-major draft convolution filters

V123 consumes the draft TP group's gathered coefficients directly in the pre- and post-convolutions. V116b already makes one full-K projection for both sides of each sublayer. Its last-dimension gather then restores a row-major coefficient tensor. At the checkpoint's TP8, two taps and 512 groups, the 512 coefficients for one tap occupy two adjacent rank slices. Each consumer reads views of those slices in their gathered layout. The model keeps the original tensor-parallel ranks, weight shards, convolution order, BF16 conversion points, KV state and all nine V116b flags. [Frozen export](validation.json) · [Two-file production change](delta.diff)

The five-layer draft invokes two filter projections per layer. Each still requires a collective. The MLP filter depends on the attention result after the post-convolution and residual normalization, so combining those two projections would change their inputs. Keeping pre-convolution activations on channel owners would require gathering the 8,192-channel hidden state for the following QKV or gate/up full-K projection. The current gather has 2,048 coefficient channels. That alternative would quadruple this payload before accounting for the output side. [Draft forward and convolution source](../../sglang/python/sglang/srt/models/dflash.py) · [V78 sharding](../v78_dflash_sharded_conv_filters/README.md)

Across ten generators, the avoided row-major copies account for up to 0.625, 2.5, 10 and 20 MiB of local writes plus reads per rank at 1, 4, 16 and 32 users respectively. Each figure assumes an eight-row draft block per request and an independently materialized copy per filter. Physical wire bytes are identical. Removing up to ten copy launches is a low-load opportunity. The source does not establish a serving speedup. [Pinned gather implementation](../../sglang/python/sglang/srt/distributed/parallel_state.py)

The production arithmetic passed 364 CPU geometry cases and 7,501,216 output-value comparisons by raw bits, including the checkpoint's 8,192 channels at all four loads. Real TP2/4/8 Gloo exercised 224 rank-scenarios, including hooks on one rank while peers kept their fast layout. Both compiled CPU Inductor convolutions matched their compiled references and allocated only their output tensor. These receipts cover the per-convolution compiler surface. The separate whole-module full-graph check found that Dynamo cannot trace `vars(projection)` in V123's eligibility guard. V123b addresses that guard.
