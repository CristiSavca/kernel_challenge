## Normal serving paths

The ordinary SP Muse outer model tail resolves the proposal after its captured inner layer body. It runs the paired projection on compatible TP4/TP8 ordinary prefill with enough payload savings, original FC and normalization modules, working PyNCCL and a compatible fused draft cache writer. The bound callback keeps canonical token order and uses all five checkpoint projections at full input width. The worker writes physical KV at original prompt positions, including the native per-layer fallback after a partial write. Original graph output trimming carries both compact-payload markers. Rejected feature paths retain the original gather, projection and writer. V182's direct prompt attention, target verification Q/K producer and FA3 fallback retain their original source and dimensions.
